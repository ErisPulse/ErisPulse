# ErisPulse 工作台

> [!TIP]
> **什么时候需要读这篇**：当你要把模块 / 适配器提交到模块商店、为模块申请一个 `plugin-xxx.erisdev.com` 网站地址、用脚本或 CI 自动提交模块、或让自己的网站支持「用 ErisPulse 账号登录」时读这篇。不需要则跳过。

[ErisPulse 工作台](https://workbench.erisdev.com/) 是生态的**统一账号中心与创作者后台**：一个账号贯通模块商店、托管域名与开放接口。它是纯在线服务，**无需安装任何包**——打开网页、登录即可使用。

```text
GitHub / Codeberg / 云湖 / 邮箱 登录
            │
            ▼
      ErisPulse 账号 ──── 两步验证（可选）
            │
   ┌────────┼─────────────┬──────────────┐
   ▼        ▼             ▼              ▼
模块管理   托管域名      访问令牌      OAuth 应用
（商店）  （网站地址）  （脚本/CI）  （第三方登录）
```

## 登录与账号

工作台支持四种登录方式，未配置的登录方式不会显示在登录页：

| 方式 | 适用场景 |
|------|---------|
| GitHub | 模块代码托管在 GitHub 的作者 |
| Codeberg | 模块代码托管在 Codeberg 的作者 |
| 云湖 | 使用云湖平台的用户 |
| 邮箱 | 没有上述账号的用户：用户名 + 邮箱 + 密码，注册时需填邮件收到的 6 位验证码 |

> [!NOTE]
> 同一账号可以在「个人资料」页绑定多个登录身份。用不同方式登录后绑定到一起，下次用任意一种都能进同一个账号。

**两步验证**：在「个人资料」页可开启基于动态口令（TOTP）的两步验证，用任意验证器 App 扫码即可。开启后，登录以及删除模块、删除域名这类敏感操作都需要输入动态码。

> [!WARNING]
> 动态口令的密钥**只在开启时显示一次**。丢失密钥将无法登录，请务必妥善保存。

## 模块管理

模块商店收录的全部模块与适配器都在工作台管理。

### 提交模块

1. 左侧进入「提交新模块」
2. 填写表单：

| 字段 | 说明 |
|------|------|
| 名称 | 模块名，与 entry-point 的键名一致 |
| 类型 | `module`（功能模块）或 `adapter`（适配器） |
| PyPI 包名 | 如 `ErisPulse-MyModule` |
| 描述 | 至少 10 个字符 |
| 作者 | 显示在商店中的作者名 |
| 仓库地址 | `github.com` 或 `codeberg.org` 上的仓库 |
| 分类 | 工具 / 娱乐 / 管理 / 通知 / AI / 平台 / 分析 |
| 标签、多语言、最低 SDK 版本 | 可选 |

3. 提交后经模块索引仓库下发，**通常数分钟内**出现在商店中

新提交的模块初始为「未验证」——表示尚未通过官方审核，用户安装时会收到风险提示。审核通过后转为「已验证」。

### 编辑与批量操作

在「模块列表」进入自己的模块详情页，可以修改描述、仓库地址、分类、标签等全部元数据，上传模块图标；也可以开启多选模式，对多个模块**批量认证 / 取消认证 / 删除**（整批操作只需输入一次动态码）。

### 归属认领

模块商店里已有、但不是经你手提交的模块（例如早期由他人代为收录），可以认领回自己的账号：

- **自动认领**：用与模块仓库相同的 GitHub / Codeberg 账号登录，系统识别到仓库归属一致时自动完成认领
- **手动认领**：在模块详情页点「认领此模块」并填写理由，由管理员审核后转移

## 托管域名

每个已收录的模块可以申请一个免费的网站地址，形如 `plugin-模块名.erisdev.com`，用于放模块主页、文档或演示站。

| 限制 | 数值 |
|------|------|
| 每个模块 | 2 个域名 |
| 每个账号 | 10 个域名 |
| 未完成验证 | 7 天后释放，域名可被他人再次申请 |

### 四种接入方式

| 方式 | 怎么用 | 适合 |
|------|--------|------|
| **仓库分支**（推荐） | 填仓库地址 + 分支名，工作台直接读取该分支下的静态文件 | 站点源码就在模块仓库里，推送即更新 |
| **重定向** | 访问该域名时 301 跳转到你指定的 `https://` 地址 | 已有自己的网站，只想要一个好记的入口 |
| **自有服务器** | 添加一条 CNAME / A / AAAA 记录指向你的服务器 | 自己部署了站点 |
| 上传静态站点 | 上传 zip 包，由平台对象存储托管 | 暂仅限内测，未全面开放 |

「仓库分支」的分支名默认填 `ep-site`——约定俗成的站点分支名，建议把站点文件放在这个独立分支里，不污染主分支代码。

### 申请流程

1. 左侧进入「托管域名」，选择要挂域名的模块（只能选自己名下的模块）
2. 填写前缀，输入时会即时检查是否可用。前缀只允许小写字母、数字和中间的连字符
3. 选择接入方式并填写对应信息，提交

**审核规则**：每个模块的**第 1 个域名直接生效**；从第 2 个起需要管理员审核，审核结果会通过邮件通知。

### 所有权验证

为防止有人把域名指到不属于自己仓库或服务器，「仓库分支」与「自有服务器」两种方式需要验证所有权：

| 方式 | 验证方法 |
|------|---------|
| 仓库分支 | 在该分支根目录放一个文件 `erisdev-site-verify.txt`，内容为工作台给出的验证码 |
| 自有服务器 | 在你的服务器上提供 `/.well-known/erisdev-verify.txt`，内容同上 |

放好文件后回到工作台点「完成验证」。验证通过前，访问该域名会显示「等待所有权验证」的提示页。

### 管理操作

每个域名卡片上可以：

- **暂停 / 恢复**：暂停后访问显示「站点已暂停」，内容保留
- **删除**：释放该域名与全部托管资源，需输入动态码
- **更换仓库或分支**：修改后回到待验证状态，重新验证即可生效

## 开放接口

工作台同时是一个 OAuth 2.0 授权服务器，对外提供两类能力。

### 访问令牌

脚本或 CI 里调用工作台接口（如自动提交模块）时，用访问令牌代替账号密码：

1. 进入「开放平台 → 访问令牌」，填名称后点「生成令牌」
2. 令牌格式为 `epat_` + 40 位十六进制，**只在生成时显示一次**
3. 请求时放在 `Authorization: Bearer epat_…` 头里

每个账号最多 10 个令牌。开启了两步验证的账号可以勾选「免动态码」——之后用这个令牌调用敏感接口时不再要求动态码，适合无人值守的 CI。

> [!TIP]
> 请求体必须是 UTF-8 编码的 JSON。Windows 终端默认 GBK，直接传中文会被服务端拒绝——先执行 `chcp 65001`，或把请求体存成文件后用 `curl --data-binary @body.json` 提交。

### OAuth 应用

想让你自己的网站或工具支持「用 ErisPulse 账号登录」：

1. 进入「开放平台」，注册一个应用：填名称和回调地址（可以多个）
2. 得到 `client_id` 和 `client_secret`——**密钥只显示一次**，可随时重置
3. 按标准 OAuth 2.0 授权码流程接入：

| 端点 | 用途 |
|------|------|
| `/oauth/authorize` | 引导用户授权 |
| `/oauth/token` | 用授权码换令牌 |
| `/api/userinfo` | 用令牌获取用户信息（不含邮箱） |

每个账号最多注册 5 个应用。

## 常见问题

### 提交后模块没有立刻出现在商店里？

模块收录经模块索引仓库异步下发，通常数分钟内生效。可在模块列表查看操作状态，显示「已应用」即为成功。

### 域名验证一直不通过？

确认验证文件的**路径和内容**都与工作台显示的完全一致（路径区分大小写、内容不要有多余空格或换行）。仓库分支方式还需确认文件在**你填写的那个分支**上。

### 域名申请后多久生效？

「仓库分支」和「重定向」不需要等待，验证通过后立即生效。「自有服务器」方式还需要等 DNS 记录在全球传播，通常几分钟。
