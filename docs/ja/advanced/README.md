# 高級トピック

このディレクトリには、ErisPulse フレームワークの高度な機能と深いトピックが含まれています。

## ドキュメントリスト

- [起動プロセスと手動制御](startup.md) - 起動フローの分解（Finder/Loader/Manager/Router）と手動による完全な起動
- [遅延ロードシステム](lazy-loading.md) - 遅延ロードモジュールシステムの動作原理、設定、イベント駆動による遅延アクティベーション（activate_on）
- [スコープ（scope）](scope.md) - 3次元スコープ制御：モジュールの可用性 / イベントのアクセス制限 / 出力アクションの制限（メソッドレベルの細かいルールとバインディング継承 merge を含む）
- [所有権（owner）システム](ownership.md) - リソースの所有と自動回収：owner コンテキストメカニズム、所有リソースの全体像、アンロード時のクリーンアップシーケンス、設計の境界
- [シャドーモジュールとグレーディングプロセス](shadow.md) - モジュールの新バージョンを独立した owner で並行実行：出力のインターセプトと記録、動作の diff 比較、promote による正式化と失敗時のロールバック
- [インタラクションセッションシステム](interaction.md) - wait_reply / セッションタイマー / 多路待ち / セッション排他リース / 受信箱 / メッセージトランザクション / フレームワークのトレース
- [モジュール間通信](module-communication.md) - RPC 協定化（module.call）、サービス契約とディレクトリ、方向性イベント、コールドスタート時の再再生、イベントの冪等性と重複除去
- [国際化 (i18n)](i18n.md) - 多言語サポート、翻訳の登録と言語の検出
- [ライフサイクル管理](lifecycle.md) - ライフサイクルイベントシステムの使用方法
- [ルーティングマネージャー](router.md) - HTTP および WebSocket のルーティング管理
- [HTTP クライアント](http-client.md) - 統一された HTTP リクエストクライアント
- [MessageBuilder 詳解](message-builder.md) - OneBot12 メッセージセグメントビルダーの二重モードの使い方
- [SQL クエリビルダー](sql-builder.md) - 一般的な SQL チェーンクエリビルダーとストレージバックエンドの抽象化
- [ストレージバックエンド](storage-backends.md) - sqlite / mysql / postgres の非同期対応ストレージバックエンドの選択、設定、切り替え
- [例外体系とキャッチガイド](errors.md) - フレームワークのすべての例外の種類、発生場所、キャッチの提案
- [セッション型システム](../standards/session-types.md) - セッション型の定義、マッピング、およびカスタム型の登録
- [Conversation 多段会話](conversation.md) - 多段会話コンテキストのインタラクションメソッド

> [!NOTE]
> Dashboard 視窗の登録、Takumi 画像のレンダリングなどの **サードパーティエコシステムモジュール** のドキュメントは、[エコシステムモジュール](../ecosystem/README.md) ディレクトリに移動しました。

## 対象読者

以下の開発者に推奨されます：

- ErisPulse の基本機能に精通している開発者
- フレームワークの内部メカニズムを深く理解したい開発者
- パフォーマンスを最適化したり、複雑な機能を実装したい開発者
