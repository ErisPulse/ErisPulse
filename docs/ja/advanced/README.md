# 高級トピック

このディレクトリには、ErisPulseフレームワークの高度なトピックが収録されています。権限管理、グレーディング、複数回の対話、ストレージバックエンドなど、深い機能をカバーし、それぞれの問題を解決します。

> [!NOTE]
> 本ディレクトリのすべては**必要に応じて参照する**専門的なドキュメントです。まず、ホームのL1コア5つの記事を読んだ後、対応するニーズが発生したときに参照してください。各記事の冒頭には「この記事を読むべきタイミング」が記載されています。

## L2 必読4篇

生産レベルのモジュールを開発する際に避けて通れない4つの記事です。複雑なモジュールを開発する前に、すべてを読むことを推奨します（ドキュメントのホームページと同一の基準）。

- [作用域（scope）](scope.md) - 3次元の作用域制御：モジュールの可用性 / イベントのアクセス制限 / 出力アクションの制限（メソッドレベルの細かいルールとバインディング継承 merge を含む）
- [所有権（owner）システム](ownership.md) - リソースの所有権と自動回収：ownerコンテキストメカニズム、所有リソースの全体像、アンロード時のクリーンアップシーケンス、ホットリロードの境界と設計境界
- [ライフサイクル管理](lifecycle.md) - ライフサイクルイベントシステム：モジュール / アダプタのロード、アンロード、リロード、無効化時の処理
- [対話セッションシステム](interaction.md) - wait_reply / セッションタイマー / 多重待ち / セッションの排他リース / 受信箱 / メッセージトランザクション / リンクトレース

## 場面別グループ分け

ドキュメントのホームページ「原理の深層理解」のグループ分け基準と一致しており、各グループの最初の記事には「理解しないとどのような落とし穴に陥るか」が記載されています。

**実行開始** —— 启動の流れ（Finder / Loader / Manager / Router）を理解していないと、モジュールのロード失敗時にログをただ見つめることしかできません。

- [起動プロセスと手動制御](startup.md) - 起動の流れの分解（Finder/Loader/Manager/Router）と手動による完全な起動
- [遅延ロードシステム](lazy-loading.md) - 遅延ロードモジュールシステムの動作原理、設定、イベント駆動による遅延活性化（activate_on）

**通信接続** —— サービス契約（`meta.services`）のホワイトリストを理解していないと、モジュール間の `module.call` は `ServiceNotProvidedError` で拒否され、原因が分からないままです。

- [モジュール間通信](module-communication.md) - RPCプロトコル化（module.call）、サービス契約とディレクトリ、方向性イベント、冷起動時の再実行、イベントの冪等性と重複除去
- [接続プールとブロードキャスト](connections.md) - 接続登録表：ブロードキャスト、グループサブスクリプション、モジュール間の転送と再利用、接続プールの確認
- [ルーターマネージャー](router.md) - HTTPとWebSocketのルーティング管理（単一引数の登録、タプルのレスポンス規約を含む）

**データストレージ** —— 接続失敗のクールダウン期間の意味を理解していないと、データベースの不安定性が発生した際に「フレームワークが落ちた」と誤解してしまう（実際は即時失敗、クールダウン後に自動的に再接続される）。

- [ストレージバックエンド](storage-backends.md) - sqlite / mysql / postgresの非同期原生ストレージバックエンドの選択、設定、切り替え
- [SQLクエリビルダー](sql-builder.md) - 一般的なSQLのチェーン式クエリビルダーとストレージバックエンドの抽象化
- [ネットワーククライアント](client.md) - 統一されたHTTPリクエストクライアント

**メッセージ対話** —— セッションの排他リースを理解していないと、2つのモジュールが同時に同じユーザーからの返信を待つ場合、互いに切断されてしまう。

- [Conversation 多回対話](conversation.md) - 多回対話コンテキストの対話メソッド
- [セッション受信箱](transcript.md) - メッセージの自動記録：保持ポリシーの調整、実行時の上書きAPIとリスク/監査
- [MessageBuilder 詳解](message-builder.md) - OneBot12メッセージセグメントビルダーの2モードの使い方
- [国際化 (i18n)](i18n.md) - 多言語サポート、翻訳登録、言語検出

**グレーディングシャドウ** —— 5つの隔離ゲートを理解していないまま本番に移行すると、シャドウの出力メッセージが本番ユーザーに外漏れしてしまう。

- [シャドウモジュールとグレーディング移行](shadow.md) - モジュールの新バージョンを独立した所有者として並行して試行実行：出力のブロッキングと記録、動作の差分比較、promoteによる移行と失敗時のロールバック

**パフォーマンスと観測** —— 問題が発生したときに再起動しかせず、指標を見ない場合は、盲目で飛んでいるようなものです。

- [パフォーマンスのベンチマークとチューニング](performance.md) - 実測ベンチマーク数値（NoneBot2との比較を含む）、ベンチマークの自動実行と回帰比較方法、チューニングのポイント

**例外と規格参考**

- [例外体系とキャッチガイド](errors.md) - フレームワークのすべての例外型、発生場所、キャッチの提案
- [セッション型システム](../standards/session-types.md) - セッション型の定義、マッピング、独自型の登録

> Dashboardウィンドウの登録、Takumi画像のレンダリングなどの**サードパーティエコシステムモジュール**のドキュメントは、[エコシステムモジュール](../ecosystem/README.md)ディレクトリに移動しました。

## 適用対象

以下の開発者向けです：

- ErisPulseの基本機能に精通している開発者
- フレームワークの内部メカニズムを深く理解したい開発者
- パフォーマンスの最適化や複雑な機能の実装が必要な開発者
