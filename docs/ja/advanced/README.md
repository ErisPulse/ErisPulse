# 高級トピック

このディレクトリには、ErisPulse フレームワークの高度な機能に関するトピックが収録されています。権限管理、グレーディング、複数回の対話、ストレージバックエンドなど、各トピックは特定の問題を解決することを目的としています。

> [!NOTE]  
> 本ディレクトリのすべてのドキュメントは**必要に応じて参照**するためのトピック文書です。まず、ホームの L1 コア 5 記事をお読みください。該当するニーズが発生した際に、このドキュメントを参照してください。各記事の冒頭には「この記事を読むべきタイミング」が記載されています。

## L2 必読 4 記事

プロダクションレベルのモジュール開発において、これらの 4 記事を読むことが欠かせません。複雑なモジュールを構築する前に、すべてを読むことを推奨します（ドキュメントのホームページと同一の基準）：

- [作用域（scope）](scope.md) - 3 次元作用域制御：モジュールの可用性 / イベントのアクセス制限 / 出力アクションの制限（メソッドレベルの細かいルールと継承マージを含む）
- [所有権（owner）システム](ownership.md) - リソースの所有権と自動回収：owner コンテキストメカニズム、所有リソースの全体像、アンロード時のクリーンアップ、ホットリロードの境界と設計境界
- [ライフサイクル管理](lifecycle.md) - ライフサイクルイベントシステム：モジュール / アダプターのロード、アンロード、リロード、無効化時の処理
- [対話セッションシステム](interaction.md) - wait_reply / セッションタイマー / 多重待機 / セッション排他リース / 受信箱 / メッセージトランザクション / リンク追跡

## シナリオ別グループ

ドキュメントのホームページ「原理の深く理解」のグループ分けと同一の基準です。各グループの最初の記事には「何を知らないと失敗するか」が明記されています。

**実行の開始** —— 启動の連鎖（Finder / Loader / Manager / Router）を理解していないと、モジュールのロード失敗時にログをただ見つめて困惑するだけです。

- [起動プロセスと手動制御](startup.md) - 启動連鎖の分解（Finder/Loader/Manager/Router）と手動での完全な起動
- [遅延ロードシステム](lazy-loading.md) - 遅延ロードモジュールシステムの動作原理、設定、イベント駆動による遅延活性化（activate_on）

**通信接続** —— サービス契約（`meta.services`）のホワイトリストを理解していないと、モジュール間の `module.call` が `ServiceNotProvidedError` により拒否され、その原因が不明になる。

- [モジュール間通信](module-communication.md) - RPC 協定化（module.call）、サービス契約とディレクトリ、指定イベント、冷起動時の再再生、イベントの冪等性と重複除去
- [接続プールとブロードキャスト](connections.md) - 接続登録表：ブロードキャスト、グループサブスクリプション、モジュール間の転送と再利用、接続プールの確認
- [ルーティングマネージャー](router.md) - HTTP と WebSocket のルーティング管理（単一引数の登録、タプルのレスポンス規約を含む）

**データストレージ** —— 接続失敗冷却期間の意味を理解していないと、データベースの不安定性で「フレームワークが止まっている」と誤解してしまう（実際は即時失敗、冷却後に自動的に再接続される）。

- [ストレージバックエンド](storage-backends.md) - sqlite / mysql / postgres の非同期ネイティブストレージバックエンドの選択、設定と切り替え
- [SQL クエリビルダー](sql-builder.md) - 一般的な SQL チェーン式クエリビルダーとストレージバックエンドの抽象化
- [ネットワーククライアント](client.md) - 統一された HTTP リクエストクライアント

**メッセージ対話** —— セッション排他リースを理解していないと、2 つのモジュールが同じユーザーの返信を待っている場合、お互いに中断される。

- [Conversation 多回対話](conversation.md) - 多回対話コンテキストの対話メソッド
- [セッション受信箱](transcript.md) - メッセージの自動記録：保持ポリシーの設定、実行時の上書き API とリスク/監査
- [MessageBuilder 詳解](message-builder.md) - OneBot12 メッセージセグメントビルダーの二重モードの使い方
- [国際化 (i18n)](i18n.md) - 多言語サポート、翻訳登録と言語検出

**グレーディングシャドウ** —— 5 つの隔離ゲートを理解していないと、シャドウモジュールの出力メッセージが本番ユーザーに外漏れしてしまう。

- [シャドウモジュールとグレーディング転正](shadow.md) - モジュールの新バージョンを独立した所有者として並行実行：出力のブロッキングと記録、動作 diff の比較、promote による転正と失敗時のロールバック

**例外と規範の参考**

- [例外体系とキャッチガイド](errors.md) - フレームワークのすべての例外タイプ、発生場所とキャッチの提案
- [セッション型システム](../standards/session-types.md) - セッション型の定義、マッピング、および独自型の登録

## 対象読者

以下の開発者に推奨されます：

- ErisPulse の基本機能に精通している開発者
- フレームワークの内部メカニズムを深く理解したい開発者
- 性能を最適化したり、複雑な機能を実装したい開発者
