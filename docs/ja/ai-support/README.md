# AI アシスト開発

本ガイドは、AIを使用してErisPulseの仕様に準拠したモジュールとアダプターのコードを迅速に生成するのに役立ちます。

## 📦 AI マテリアルドキュメント

ErisPulseは、完全なAI開発用マテリアルドキュメントを提供しており、AIに直接読み込ませることで、仕様に準拠したコードを生成できます。

### ドキュメントの種類

| ドキュメント名 | 適用シナリオ | コンテンツ規模 | 推奨度 |
|---------|----------|---------|--------|
| **ErisPulse-ModuleDev.md** | モジュール開発 | 中程度 | ⭐⭐⭐⭐⭐ |
| **ErisPulse-AdapterDev.md** | アダプター開発 | 中程度 | ⭐⭐⭐⭐⭐ |
| **ErisPulse-Full.md** | 完全な開発リファレンス | 大規模 | ⭐⭐⭐ |

### マテリアルドキュメントの入手

#### GitHub Releasesからダウンロード

新しいバージョンがリリースされるたびに、最新のAIマテリアルドキュメントがGitHub Releasesで提供されます。
または、このディレクトリでドキュメントと共に更新されるAIマテリアルドキュメントをダウンロードすることもできます。

## よくある質問

### Q: どのようなAIツールをおすすめしますか？

A: 以下のAIツールをおすすめします：
- **VS Code + GitHub Copilot**：ファイルシステムを直接操作できます
- **Cursor**：強力なAIコーディングアシスタント
- **ChatGPT / Claude**：対話を通じてコードを生成できます

### Q: AIが生成したコードに問題がある場合はどうすればよいですか？

A: 以下の手順で処理することをお勧めします：
1. AIが正しいドキュメントのバージョンを使用しているか確認する
2. AIにより詳細な要件記述を提供する
3. AIに段階的に生成させ、順次検証する
4. サンプルテンプレートを参考に、より具体的な例を提供する

### Q: AIがより高品質なコードを生成するようにするにはどうすればよいですか？

A: 以下をお勧めします：
1. すべての詳細を含む詳細な要件記述を提供する
2. 入力と出力を含む具体的な例を提供する
3. 使用するドキュメントのバージョンを明確に指定する
4. AIにコメントとドキュメント文字列（docstring）の追加を要求する
