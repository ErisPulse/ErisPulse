# AI補助開発

ErisPulse は、最新のフレームワーク仕様に基づいてコードを生成できる2種類の補完的な AI 補助開発方式を提供しています：

- **素材ドキュメント**：一度にコンテキストを注入する大規模な Markdown ファイル。プロジェクト全体の開発に適しています。
- **MCP サーバー**：AI が公式ドキュメントを必要なときに検索できるようにします。日常的なコード補完や API 検索に適しています。

| | 素材ドキュメント | MCP サーバー |
|---|---|---|
| 形式 | 一度に注入する大規模な Markdown | AI が必要に応じて検索 |
| コンテキストコスト | 高い（トークンを消費） | 低い（関連する断片のみ取得） |
| 時効性 | バージョンリリースごとに更新 | 実時（GitHub から取得 + キャッシュ） |
| 適合 | 大きなコンテキスト窓を持つ場合、プロジェクト全体の開発に | 日常的なコード補完、API 検索に |
| クライアント | 任意の AI ツール | MCP をサポートするクライアントのみ |

これらは互いに矛盾しません。大型プロジェクトを開発する際には、両方を同時に使用できます。素材ドキュメントで基礎を構築し、MCP で漏れを補います。

## 素材ドキュメント

素材ドキュメントは `prompts/` ディレクトリにあり、開発シナリオに応じて3種類に分かれています。

| ドキュメント | シナリオ | 説明 |
|------|------|------|
| **ErisPulse-ModuleDev.md** | モジュール開発 | 事件処理、ルーティング、ライフサイクルなど、モジュール開発の全プロセスをカバー |
| **ErisPulse-AdapterDev.md** | アダプタ開発 | モジュール開発の上に、アダプタのコアコンセプト、SendDSL、プラットフォーム適応ガイドを追加 |
| **ErisPulse-Full.md** | フルスタックリファレンス | 上記すべての内容 + 完全なユーザーガイドと API リファレンスの集約 |

入手方法：`prompts/` ディレクトリから直接入手（ドキュメントと同期して更新）、または [GitHub Releases](https://github.com/ErisPulse/ErisPulse/releases) から対応バージョンをダウンロード。

### 使用方法

1. 目的に応じてドキュメントを選択（モジュール → `ModuleDev`、アダプタ → `AdapterDev`、複雑な要件 → `Full`）
2. ドキュメント内容を AI にコンテキストとして提供：IDE 内にワークスペースとして配置、対話形式では直接貼り付け、API 呼び出しでは system message として注入
3. 下記のテンプレートに従って要件を記述。詳細が具体的であれば、生成品質が向上します。

### 要求記述テンプレート

**モジュール：**

```
ErisPulse モジュール開発規格に基づき、[モジュール名] モジュールの完全なコードを生成してください。

機能説明：[コア機能]
監視する必要のあるイベント：[メッセージ / コマンド / 通知 / 要求]、処理ロジック：[操作]
必要な設定項目：[キー名]：[用途]（[必須/任意]、デフォルト値：[値]）
その他の要件：[追加制約]
```

**アダプタ：**

```
ErisPulse アダプタ開発規格に基づき、[アダプタ名] アダプタの完全なコードを生成してください。

プラットフォーム情報：[名称]、通信プロトコル：[WebSocket / WebHook / HTTP ポーリング]、API ドキュメント：[アドレス]
イベント変換：プラットフォームイベント [タイプ] → OneBot12 映射 [関係]
実装する必要のある送信メソッド：[Text / Image / Voice ...]
設定項目：[キー名]：[用途]（[必須/任意]）
```

## MCP サーバー

ErisPulse は公式の **MCP（Model Context Protocol）サーバー**を提供しており、[`mcp.erisdev.com`](https://mcp.erisdev.com/) に展開されています。MCP をサポートする AI コードアシスタント（Claude Desktop、Cursor など）に接続することで、AI はコードを書いているときに**直接 ErisPulse 公式ドキュメントを検索・参照**できます。手動で貼り付ける必要はありません。

### 提供されるツール

接続後、AI は以下のツールを利用できます。

| ツール | パラメータ | 説明 |
|------|------|------|
| **`search_docs`** | `query` (必須), `top_k?=5`, `lang?=zh-CN` | BM25 キーワード検索。複数のキーワードを一度に渡すことができます。 |
| **`read_document`** | `doc_path` (必須), `lang?=zh-CN` | 単一のドキュメントの完全な Markdown を読み取ります。 |
| **`list_documents`** | `lang?=zh-CN` | 現在の言語で利用可能なすべてのドキュメントのタイトル、パス、分類をリストアップします。 |
| **`list_languages`** | — | ドキュメントがサポートするすべての言語とドキュメント数をリストアップします。 |

サポート言語：`zh-CN` / `en` / `zh-TW` / `ja` / `ru`。検索のコツ：**整文ではなく複数のキーワード**を使用してください。例えば `コマンド登録 イベント監視` は `コマンドを登録する方法` よりも効果的です。

### Claude Desktop への接続

設定ファイルを編集します（macOS：`~/Library/Application Support/Claude/claude_desktop_config.json`；Windows：`%APPDATA%\Claude\claude_desktop_config.json`）：

```json
{
  "mcpServers": {
    "erispulse": {
      "url": "https://mcp.erisdev.com/"
    }
  }
}
```

> Claude Desktop 0.85+ が必要です。古いバージョンは `mcp-remote` ブリッジを使用できます：`{ "command": "npx", "args": ["mcp-remote", "https://mcp.erisdev.com/"] }`。

### Cursor への接続

`~/.cursor/mcp.json`（グローバル）またはプロジェクト内の `.cursor/mcp.json` を編集します：

```json
{
  "mcpServers": {
    "erispulse": {
      "url": "https://mcp.erisdev.com/"
    }
  }
}
```

サービスはデフォルトで公開されており、Token は必要ありません。悪用防止のため、IP ごとのリクエスト制限（1 IP 毎分 60 回）が適用されています。Worker のソースコードはこのリポジトリの workers フォルダにあり、自前でデプロイすることも可能です。

## 一般的な質問

**生成されたコードが期待通りでない場合は？**
ドキュメントを完全に提供しているか確認してください。要件にさらに詳細（入出力例、境界条件）を追加してください。AI に段階的に生成させましょう（まず骨格、次に機能を追加）。[examples/](../../examples/) ディレクトリの例を参照して、追加のコンテキストを補足してください。

**MCP 接続後、AI が `search_docs` を呼び出さない場合は？**
クライアントが該当サーバーをロードしているか確認してください（Claude Desktop は再起動後、右下にアイコンが表示されるはずです）。一部のクライアントでは、プロンプト内で「ErisPulse ドキュメントツールを使って API を確認する」などと明示的に指示する必要があります。
