## Install

1. Download `skills-<lang>.zip` from this directory (or copy the directory as-is)
2. Unzip and move the skill directories into your agent's skill folder (e.g. `.zcode/skills/`, `.claude/skills/`)
3. Agents activate them automatically based on each skill's `description`

> Generated by `python -m scripts.tools gen skills`; do not edit by hand.
