# スタイルガイド

このディレクトリには、ErisPulse プロジェクトのコードおよびドキュメントのスタイル規約が含まれています。

## ドキュメントリスト

- [注釈スタイル規格](docstring.md) - メソッドの注釈とドキュメント文字列のフォーマット規格

## 対象読者

このドキュメントは以下の開発者向けです：

- ErisPulse コア貢献者
- モジュールおよびアダプター開発者
- API ドキュメントの生成を必要とする開発者

## 目的

スタイルガイドの目的は以下の通りです：

- コードのコメントの一貫性を確保する
- 自動 API ドキュメント生成をサポートする
- コードの可読性と保守性を向上させる

## 規範に従うメリット

- 統一されたコードスタイル
- 完備した API ドキュメント
- より良いチーム協力
- 自動ドキュメント生成のサポート
