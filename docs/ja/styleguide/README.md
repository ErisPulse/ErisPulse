# スタイルガイド

このディレクトリには、ErisPulse プロジェクトのエンジニアリング規律と書式規則が含まれています。

## ドキュメント一覧

- [用語集（唯一の信頼できる情報源）](glossary.md) - Client/HttpClient、storage/env/StorageManager、BaseConfig/AdapterConfig、scope の 3 つの次元、オーナーシップ、サービス契約/ディレクトリ/ホワイトリストなど、ドリフトしやすい用語の唯一の定義
- [コメントスタイル規約](docstring.md) - メソッドコメントとドキュメント文字列の形式規範およびタグ解析の契約
- [エンジニアリング堅牢性ルール](engineering.md) - 例外トレースのレベル分け、ログのレベル分け、振る舞いパラメータの一元化、API 契約、シングルトン逆参照の禁忌、クリーンアップとロールバックの規律、テスト規律
- [ドキュメントおよび対外執筆ルール](docs-writing.md) - ドキュメントの文章スタイル、バージョン表記、README とリリースページの三段構成、シナリオベースの表現、変更履歴の執筆

## 対象者

- ErisPulse コア貢献者
- モジュールおよびアダプター開発者
- README および外部ページの維持に貢献する者
- API ドキュメントを生成する必要のある開発者

## 他の規格との関係

- [技術標準](../standards/) - アダプタの**技術**仕様（セッションの型、イベントの変換、APIの形態）；このディレクトリは**エンジニアリングと執筆**の規律であり、両者は補完的で重複しません
- `CONTRIBUTING.md` - 貢献のプロセスとCIのチェックポイント（このディレクトリの規則の中の機械検査可能な部分は、チェックスクリプトによって実行されます）
- `CHANGELOG.md`の冒頭にある「執筆規範」 - 変更履歴の詳細な規格（本文書では本文を繰り返さず、引用のみ行います）
