# 開発者ガイド

> [!TIP]
> **このドキュメントを読むべきタイミング**：ErisPulse 向けの拡張機能——ボットに機能（モジュール）を追加する、または新しいプラットフォーム（アダプター）に接続する——を開発する準備をする際です。ボットの利用のみが目的の場合は読み飛ばして、[クイックスタート](../quick-start.md)を直接ご覧ください。

ここからあなたの開発パスを見つけましょう：**モジュール開発**では、コマンドやメッセージハンドラを使ってボットの機能を拡張できます。**アダプター開発**では、ボットを新しいメッセージプラットフォームに接続できます。どちらのパスも、プロジェクトの作成からテスト、公開までの完全な流れをカバーしています。

## 開発の準備

開発を始める前に、以下を確認してください：

1. [基本概念](../getting-started/basic-concepts.md)を読んでいる
2. [イベント処理](../getting-started/event-handling.md)に慣れている
3. 開発環境をインストールしている（Python >= 3.10）
4. ErisPulse SDK をインストールしている

## 開発タイプの選択

あなたのニーズに合わせて適切な開発タイプを選択してください：

| 開発タイプ | 適用シーン | 入門ガイド |
|---------|---------|---------|
| **モジュール開発** | ボット機能の拡張、ビジネスロジックの実装、コマンドとメッセージ処理の提供 | [モジュール開発入門](modules/getting-started.md) |
| **アダプター開発** | 新しいメッセージプラットフォームへの接続、クロスプラットフォーム通信の実現、プラットフォーム固有機能の提供 | [アダプター開発入門](adapters/getting-started.md) |

> ボットの機能を拡張したい場合（コマンドの追加やメッセージの処理など）は、**モジュール開発**を選択してください。ボットを新しいプラットフォームに接続する必要がある場合は、**アダプター開発**を選択してください。

- [アダプターのサンプル](https://github.com/ErisPulse/ErisPulse/tree/main/examples/example-adapter) - アダプターの完全なプロジェクト構造

### 開発モード

ホットリロードモードで開発すると、コードの変更後に自動的にリロードされます：

```bash
epsdk run main.py --reload
```

### デバッグのヒント

`config/config.toml` で DEBUG または TRACE レベルのログを有効にします：

```toml
[ErisPulse.logger]
# DEBUG: モジュールのロード、ルーティング登録などの開発デバッグ情報を出力
# TRACE: 最低レベル。イベントディスパッチ、ストレージへの書き込み、遅延読み込みなどフレームワーク内部の詳細な処理フローを出力
level = "DEBUG"
```
