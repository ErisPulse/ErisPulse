# エコシステムモジュール

ErisPulse フレームワーク自体は、コア機能（イベントシステム、モジュールシステム、設定、ルーティング、ログなど）のみを提供し、**GUI、画像描画、可視化などの「重い」機能は組み込みではありません**。これらの機能はコミュニティがメンテナンスしている **サードパーティモジュール** によって提供されており、必要に応じてインストールするだけです。

> [!IMPORTANT]
> 本ディレクトリ以下のすべてのドキュメントに記載されているモジュールは **個別にインストールが必要** です。ErisPulse フレームワークに同梱されるものではありません：
>
> ```bash
> epsdk install <モジュール名>
> ```

## 自分のモジュールもここに載せたい？

高品質で、広く再利用可能な ErisPulse エコシステムモジュールの紹介をお待ちしています。要件：

1. [PyPI](https://pypi.org/) に公開されており、パッケージ名が `ErisPulse-` で始まる
2. 基本的な README と使用例を提供する
3. 活発にメンテナンスし、Issue に対応する

上記の条件を満たすモジュールの作者は、PR を通じて本ディレクトリに `<モジュール名>.md` のドキュメントを追加し、本表の「おすすめモジュール」に一行追加することができます。
