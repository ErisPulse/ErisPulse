# 風格指南

本目錄包含 ErisPulse 項目的程式碼和文件風格規範。

## 文件清單

- [註釋風格規範](docstring.md) - 方法註釋和文件字串的格式規範

## 適用對象

這些文件適合以下開發者：

- ErisPulse 核心貢獻者
- 模組和適配器開發者
- 需要產生 API 文件的開發者

## 目的

風格指南的目的：

- 確保程式碼註釋的一致性
- 支援自動 API 文件產生
- 提高程式碼的可讀性與可維護性

## 遵循規範的好處

- 統一的代碼風格
- 完善的 API 文件
- 更好的團隊協作
- 自動化文件生成支援
