# Документация по функциям платформы Terminal

TerminalAdapter — это адаптер командной строки. Терминал — это чат-сессия, используемая для локальной быстрой отладки логики модуля.

---

## Информация о документации

- Версия соответствующего модуля: 1.1.0
- Ответственный: ErisPulse

## Основная информация

- Краткое описание платформы: интерфейс командной строки, действующий как чат-сессия, где ввод stdin является сообщением, а модули отвечают, выводя результаты непосредственно в терминал
- Название адаптера: TerminalAdapter
- Идентификатор платформы: `terminal`
- Дизайн для одного аккаунта (сценарий локальной отладки)
- Требования к фреймворку: мягкая зависимость от `ErisPulse>=2.7.1` (проверка во время выполнения с предупреждением, не обязательная)

## Инструкция по настройке

```toml
[Terminal]
bot_id = "terminal_bot"   # ID робота-песочницы
bot_name = "Terminal"     # Отображаемое имя
```

## Обновление парадигмы v5 (1.1.0)

- **Принадлежность задачи spawn_background**: Цикл чтения stdin теперь использует `runtime.spawn_background`
- **Мягкая зависимость от фреймворка**: Проверка наличия `ErisPulse>=2.7.1` с выводом предупреждения; логирование версии при запуске

## Использование

```python
# Модуль по-прежнему слушает сообщения
from ErisPulse.Core.Event import message

@message.on_message()
async def handle(event):
    if event.get("platform") == "terminal":
        await event.reply("Получено: " + event.get_text())
```

- Текст, введённый в терминале, является сообщением пользователя и поддерживает несколько строк (оканчивается пустой строкой)
- Подходит для быстрой проверки логики модуля на этапе разработки, не требует подключения к реальной платформе
