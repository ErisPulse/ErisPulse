# AI-помощь в разработке

ErisPulse предоставляет два взаимодополняющих способа AI-помощи в разработке, позволяющих генерировать код на основе последних спецификаций фреймворка:

- **Документация по материалам**: большой Markdown-файл, загружаемый в контекст единовременно, подходит для разработки целого проекта
- **MCP-сервер**: позволяет AI по запросу извлекать официальную документацию, подходит для повседневного дополнения кода и поиска API

| | Документация по материалам | MCP-сервер |
|---|---|---|
| Формат | Один большой Markdown-файл, **загружается единовременно** | AI **по запросу извлекает** |
| Стоимость контекста | Высокая (занимает токены) | Низкая (извлекаются только соответствующие фрагменты) |
| Актуальность | Обновляется вместе с выпуском версии | Реальное время (сбор с GitHub + кэширование) |
| Подходит для | Проекты с большим окном контекста, разработка целого проекта | Повседневное дополнение кода, поиск API |
| Клиент | Любой инструмент AI | Только клиенты, поддерживающие MCP |

Оба способа не исключают друг друга: при разработке крупного проекта можно использовать их одновременно — документация по материалам в качестве основы, а MCP-сервер — для поиска и заполнения пробелов.

## Документация по материалам

Документация по материалам находится в каталоге `prompts/` и разделена на три вида по сценариям разработки:

| Документ | Сценарий | Описание |
|------|------|------|
| **ErisPulse-ModuleDev.md** | Разработка модуля | Охватывает весь процесс разработки модуля (обработка событий, маршрутизация, жизненный цикл и т.д.) |
| **ErisPulse-AdapterDev.md** | Разработка адаптера | Помимо разработки модуля, включает основные концепции адаптера, SendDSL, руководство по адаптации к платформе |
| **ErisPulse-Full.md** | Полное руководство | Всё вышеперечисленное + полное руководство пользователя и справочник API |

Способы получения: напрямую из каталога `prompts/` (с синхронизацией с документацией), или загрузить нужную версию с [GitHub Releases](https://github.com/ErisPulse/ErisPulse/releases).

### Способы использования

1. Выберите нужный документ в зависимости от задачи (модуль → `ModuleDev`, адаптер → `AdapterDev`, сложные задачи → `Full`)
2. Передайте содержимое документа в качестве контекста AI: поместите в рабочую область IDE, вставьте в чат, или передайте как system message при API-вызове
3. Используйте шаблон описания задачи ниже, чем конкретнее описание, тем выше качество генерации

### Шаблон описания задачи

**Модуль:**

```
Пожалуйста, на основе спецификации разработки модуля ErisPulse, сгенерируйте полный код модуля [название модуля].

Описание функции: [основная функция]
События, которые нужно отслеживать: [сообщения / команды / уведомления / запросы], логика обработки: [операции]
Необходимые параметры конфигурации: [ключ]: [назначение] ([обязательно/необязательно], значение по умолчанию: [значение])
Дополнительные требования: [дополнительные ограничения]
```

**Адаптер:**

```
Пожалуйста, на основе спецификации разработки адаптера ErisPulse, сгенерируйте полный код адаптера [название адаптера].

Информация о платформе: [название], протокол связи: [WebSocket / WebHook / HTTP-опрос], документация API: [адрес]
Конвертация событий: платформенное событие [тип] → OneBot12 [отображение]
Необходимые реализуемые методы отправки: [текст / изображение / голос и т.д.]
Параметры конфигурации: [ключ]: [назначение] ([обязательно/необязательно])
```

## MCP-сервер

ErisPulse предоставляет официальный **MCP (Model Context Protocol) сервер**, размещенный по адресу [`mcp.erisdev.com`](https://mcp.erisdev.com/). После подключения к AI-редактору, поддерживающему MCP (Claude Desktop, Cursor и др.), AI сможет **непосредственно извлекать и просматривать официальную документацию ErisPulse** при написании кода, без необходимости вручную вставлять текст.

### Предоставляемые инструменты

После подключения AI получит следующие инструменты:

| Инструмент | Параметры | Описание |
|------|------|------|
| **`search_docs`** | `query` (обязательно), `top_k?=5`, `lang?=zh-CN` | Поиск по ключевым словам с помощью BM25, можно передать несколько ключевых слов за раз |
| **`read_document`** | `doc_path` (обязательно), `lang?=zh-CN` | Чтение полного Markdown-документа |
| **`list_documents`** | `lang?=zh-CN` | Вывод заголовков, путей и категорий всех доступных документов на текущем языке |
| **`list_languages`** | — | Вывод всех поддерживаемых языков документации и количества документов на каждом |

Поддерживаемые языки: `zh-CN` / `en` / `zh-TW` / `ja` / `ru`. Советы по поиску: используйте **несколько ключевых слов**, а не целые фразы, например `регистрация команды прослушивание событий` лучше, чем `как зарегистрировать команду`.

### Подключение к Claude Desktop

Отредактируйте конфигурационный файл (macOS: `~/Library/Application Support/Claude/claude_desktop_config.json`; Windows: `%APPDATA%\Claude\claude_desktop_config.json`):

```json
{
  "mcpServers": {
    "erispulse": {
      "url": "https://mcp.erisdev.com/"
    }
  }
}
```

> Требуется Claude Desktop 0.85+. Для старых версий можно использовать мост `mcp-remote`: `{ "command": "npx", "args": ["mcp-remote", "https://mcp.erisdev.com/"] }`.

### Подключение к Cursor

Отредактируйте `~/.cursor/mcp.json` (глобально) или `.cursor/mcp.json` в проекте:

```json
{
  "mcpServers": {
    "erispulse": {
      "url": "https://mcp.erisdev.com/"
    }
  }
}
```

Сервис по умолчанию открыт, токен не требуется. Для предотвращения злоупотреблений установлен лимит запросов (60 запросов в минуту на IP). Исходный код Worker находится в папке `workers` данного репозитория, поддерживается самостоятельная развертка.

## Часто задаваемые вопросы

**Сгенерированный код не соответствует ожиданиям?**
Проверьте, предоставлена ли полная документация; добавьте больше деталей в описание задачи (примеры входных/выходных данных, граничные условия); попросите AI генерировать пошагово (сначала структуру, затем функциональность); обратитесь к примерам в каталоге [examples/](../../examples/) в качестве дополнительного контекста.

**После подключения к MCP AI не вызывает `search_docs`?**
Убедитесь, что клиент загрузил этот сервер (после перезапуска Claude Desktop в правом нижнем углу должен появиться значок); в некоторых клиентах нужно явно указать в промпте «используйте инструменты документации ErisPulse для проверки API».
