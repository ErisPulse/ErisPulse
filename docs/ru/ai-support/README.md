# AI-ассистированная разработка

Этот гид поможет вам использовать ИИ для быстрого генерации кода модулей и адаптеров в соответствии со спецификациями ErisPulse.

## 📦 AI-документация для материалов

ErisPulse предоставляет полную документацию по разработке материалов для ИИ, которую можно напрямую передавать ИИ для генерации кода в соответствии со спецификациями.

| **ErisPulse-AdapterDev.md** | Разработка адаптеров | Средний | ⭐⭐⭐⭐⭐ |

### Получение документации по материалам

#### Скачивание из GitHub Releases

При каждом выпуске новой версии в GitHub Releases предоставляется самая последняя документация по материалам для ИИ.
Кроме того, вы можете скачать документацию по материалам для ИИ в этом каталоге, которая обновляется вместе с документацией.

## Часто задаваемые вопросы

### Q: Какие AI-инструменты рекомендуется использовать?

A: Рекомендуется использовать следующие AI-инструменты:
- **VS Code + GitHub Copilot**: можно напрямую управлять файловой системой
- **Cursor**: мощный помощник по кодированию на ИИ
- **ChatGPT / Claude**: можно генерировать код через диалог

### Q: Что делать, если код, сгенерированный ИИ, содержит ошибки?

A: Рекомендуется обработать следующим образом:
1. Проверить, использует ли ИИ правильную версию документации
2. Предоставить ИИ более детальное описание требований
3. Попросить ИИ генерировать код поэтапно и проверять шаг за шагом
4. Обратиться к образцам шаблонов и предоставить более конкретные примеры

### Q: Как заставить ИИ генерировать код более высокого качества?

A: Рекомендации:
1. Предоставить детальное описание требований, включая все детали
2. Предоставить конкретные примеры, включая входные и выходные данные
3. Четко указать используемую версию документации
4. Попросить ИИ добавить комментарии и документирующие строки
