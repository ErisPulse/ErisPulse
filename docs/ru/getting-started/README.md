## Выбор способа разработки

ErisPulse поддерживает два способа разработки:

| Способ | Сценарий использования | Описание |
|------|---------|------|
| **Встраиваемая разработка** | Быстрые прототипы, внутренние функции проекта | Непосредственно в `main.py` пишите обработчики, без необходимости создания отдельного модуля |
| **Модульная разработка** (рекомендуется) | Продуктовая среда, распределение функций | Создание отдельного пакета Python, который устанавливается и используется через `epsdk install` |

> Подробное сравнение и примеры обоих способов см. в [Создание первого робота](first-bot.md) и [Введение в модульную разработку](../developer-guide/modules/getting-started.md).

## Обзор архитектуры

ErisPulse использует архитектуру, основанную на событиях, и состоит из следующих систем:

- **Система адаптеров** — Общение с различными платформами, преобразование платформенных событий в единый стандарт OneBot12
- **Система событий** — Обработка пяти типов событий: сообщения, команды, уведомления, запросы, мета-события
- **Система модулей** — Расширение функциональности через отдельные модули, поддержка управления зависимостями и ленивая загрузка
- **Основные модули** — Предоставляют базовые возможности, такие как Storage (хранилище), Config (конфигурация), Logger (логирование), Router (маршрутизация)

> Подробную схему архитектуры и процесс инициализации см. в [Обзор архитектуры](../architecture.md).
