## Выбор способа разработки

ErisPulse поддерживает два способа разработки:

| Способ | Область применения | Описание |
|------|---------|------|
| **Встраиваемая разработка** | Быстрое прототипирование, внутренние функции проекта | Написание обработчиков непосредственно в `main.py`, без необходимости создания отдельного модуля |
| **Модульная разработка** (рекомендуется) | Продуктовая среда, распространение функций | Создание отдельного пакета Python, который устанавливается и используется через `epsdk install` |

> Подробное сравнение и примеры обоих способов см. в [Создание первого бота](first-bot.md) и [Введение в модульную разработку](../developer-guide/modules/getting-started.md).

## Обзор архитектуры

ErisPulse использует событийно-ориентированную архитектуру, состоящую из следующих основных систем:

- **Система адаптеров** — взаимодействие с различными платформами, преобразование событий платформы в единый стандарт OneBot12
- **Система событий** — обработка пяти основных типов событий: сообщения, команды, уведомления, запросы и метасобытия
- **Система модулей** — расширение функциональности через отдельные модули, поддержка управления зависимостями и ленивого загрузки
- **Основные модули** — предоставление базовых возможностей, таких как Storage (хранение), Config (конфигурация), Logger (логирование), Router (маршрутизация) и т.д.

> Подробная схема архитектуры и процесс инициализации см. в [Обзор архитектуры](../architecture.md).
