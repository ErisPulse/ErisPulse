# Установка и настройка

В этом руководстве объясняется, как установить ErisPulse и настроить ваш проект.

## Требования к системе

- Python 3.10 или выше (рекомендуется 3.10 - 3.13)
- pip или uv (рекомендуется)
- Достаточно свободного места на диске (минимум 100 МБ)

## Способы установки

### Способ 1: Установка с помощью pip

```bash
# Установить ErisPulse
pip install ErisPulse

# Обновить до последней версии
pip install ErisPulse --upgrade
```

### Способ 2: Установка с помощью uv (рекомендуется)

uv — это более быстрый инструментарий Python, рекомендуемый для среды разработки.

#### Установка uv

```bash
# Установить uv с помощью pip
pip install uv

# Проверить установку
uv --version
```

#### Создание виртуального окружения

```bash
# Создать директорию проекта
mkdir my_bot && cd my_bot

# Установить Python 3.12
uv python install 3.12

# Создать виртуальное окружение
uv venv
```

#### Активация виртуального окружения

```bash
# Windows
.\venv\Scripts\activate

# Linux/Mac
source .venv/bin/activate
```

#### Установка ErisPulse

```bash
# Установить ErisPulse
uv pip install ErisPulse --upgrade
```

## Инициализация проекта

### Интерактивная инициализация

```bash
epsdk init
```

Следуйте инструкциям для завершения:
1. Ввести название проекта
2. Выбрать уровень логирования
3. Настроить параметры сервера
4. Выбрать адаптер
5. Настроить параметры адаптера

### Быстрая инициализация

```bash
# Быстрый режим, пропуск интерактивной настройки
epsdk init -q -n my_bot
```

### Описание конфигурации

После инициализации будет создан файл `config/config.toml`:

```toml
[ErisPulse.server]
host = "0.0.0.0"
port = 8000

[ErisPulse.logger]
level = "INFO"

[ErisPulse.framework]
enable_lazy_loading = true

```

## Установка модулей

### Из удаленного репозитория

```bash
# Установить указанный модуль
epsdk install Yunhu

# Установить несколько модулей
epsdk install Yunhu Weather
```

### Из локального каталога

```bash
# Установить локальный модуль
epsdk install ./my-module
```

### Интерактивная установка

```bash
# Войти в интерактивный режим установки без указания имени пакета
epsdk install
```

## Проверка установки

### Проверка установки

```bash
# Проверить версию ErisPulse
epsdk --version
```

### Запуск тестов

```bash
# Запустить проект
epsdk run main.py
```

Если вы увидите подобный вывод, установка прошла успешно:

```
[INFO] Инициализация ErisPulse...
[INFO] Адаптер загружен: Yunhu
[INFO] Модуль загружен: MyModule
[INFO] Инициализация ErisPulse завершена
```

## Частые вопросы

### Установка не удалась

1. Проверьте, что версия Python >= 3.10 (рекомендуется 3.10 - 3.13).
2. Попробуйте использовать `uv pip install ErisPulse` вместо `pip install`.
3. Если появляется ошибка прав доступа, попробуйте `pip install --user ErisPulse` или используйте виртуальное окружение.
4. Если вы находитесь в корпоративной среде и получаете ошибку SSL сертификата, попробуйте `pip install --trusted-host pypi.org --trusted-host files.pythonhosted.org ErisPulse`.
5. Убедитесь, что сетевое подключение работает, а источники pip доступны.

### Ошибка конфигурации

1. Проверьте синтаксис файла `config.toml` (формат TOML чувствителен к отступам и кавычкам).
2. Убедитесь, что все необходимые параметры конфигурации заполнены.
3. Просмотрите логи терминала для получения подробной информации об ошибке.
4. Используйте `epsdk init` для повторной генерации файла конфигурации.

### Не удалось установить модуль

1. Убедитесь, что название модуля указано правильно (с учетом регистра).
2. Проверьте сетевое подключение.
3. Используйте `epsdk list-remote` для просмотра списка доступных модулей.
4. Убедитесь, что модуль совместим с вашей текущей версией SDK.

### Выполнение PowerShell

Если PowerShell сообщает: "Не удалось загрузить файл... так как в этой системе запрещено выполнение скриптов":

```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```
