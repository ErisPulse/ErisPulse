# Установка и настройка

В этом руководстве описывается, как установить ErisPulse и настроить ваш проект.

## Требования к системе

- Python 3.10 или выше
- pip или uv (рекомендуется)
- Достаточное свободное место на диске (минимум 100 МБ)

## Способы установки

### Способ 1: Установка с помощью pip

```bash
# Установка ErisPulse
pip install ErisPulse

# Обновление до последней версии
pip install ErisPulse --upgrade
```

### Способ 2: Установка с помощью uv (рекомендуется)

uv — это более быстрый инструмент для Python, рекомендуемый для рабочей среды разработки.

#### Установка uv

```bash
# Установка uv с помощью pip
pip install uv

# Проверка установки
uv --version
```

#### Создание виртуального окружения

```bash
# Создание директории проекта
mkdir my_bot && cd my_bot

# Установка Python 3.12
uv python install 3.12

# Создание виртуального окружения
uv venv
```

#### Активация виртуального окружения

```bash
# Windows
.venv\Scripts\activate

# Linux/Mac
source .venv/bin/activate
```

#### Установка ErisPulse

```bash
# Установка ErisPulse
uv pip install ErisPulse --upgrade
```

## Инициализация проекта

### Интерактивная инициализация

```bash
epsdk init
```

Следуйте инструкциям:
1. Введите имя проекта
2. Выберите уровень логирования
3. Настройте параметры сервера
4. Выберите адаптер
5. Настройте параметры адаптера

### Быстрая инициализация

```bash
# Быстрый режим, пропуск интерактивной настройки
epsdk init -q -n my_bot
```

### Описание конфигурации

После инициализации будет создан файл `config/config.toml`:

```toml
[ErisPulse.server]
host = "0.0.0.0"
port = 8000

[ErisPulse.logger]
level = "INFO"

[ErisPulse.framework]
enable_lazy_loading = true

```

## Установка модулей

### Установка из удаленного репозитория

```bash
# Установка указанного модуля
epsdk install Yunhu

# Установка нескольких модулей
epsdk install Yunhu Weather
```

### Установка из локального источника

```bash
# Установка локального модуля
epsdk install ./my-module
```

### Интерактивная установка

```bash
# Без указания имени пакета — переход в интерактивный режим установки
epsdk install
```

## Проверка установки

### Проверка установки

```bash
# Проверка версии ErisPulse
epsdk --version
```

### Запуск теста

```bash
# Запуск проекта
epsdk run main.py
```

Если вы видите примерно следующий вывод, значит установка прошла успешно:

```
[INFO] Инициализация ErisPulse...
[INFO] Загружен адаптер: Yunhu
[INFO] Загружен модуль: MyModule
[INFO] Инициализация ErisPulse завершена
```

## Распространённые проблемы

### Ошибка установки

1. Проверьте, что версия Python >= 3.10 (рекомендуется 3.10 - 3.13)
2. Попробуйте использовать `uv pip install ErisPulse` вместо `pip install`
3. Если возникает ошибка прав, попробуйте `pip install --user ErisPulse` или используйте виртуальное окружение
4. Если в корпоративной среде с прокси-сервером возникает ошибка SSL-сертификата, попробуйте `pip install --trusted-host pypi.org --trusted-host files.pythonhosted.org ErisPulse`
5. Убедитесь, что подключение к интернету работает, и репозиторий pip доступен

### Ошибка конфигурации

1. Проверьте синтаксис файла `config.toml` (TOML чувствителен к отступам и кавычкам)
2. Убедитесь, что все необходимые параметры заполнены
3. Посмотрите логи в терминале для получения подробной информации об ошибке
4. Используйте `epsdk init`, чтобы пересоздать файл конфигурации

### Ошибка установки модуля

1. Убедитесь, что имя модуля написано правильно (регистр имеет значение)
2. Проверьте подключение к интернету
3. Используйте `epsdk list-remote`, чтобы посмотреть список доступных модулей
4. Убедитесь, что модуль совместим с текущей версией SDK

### Стратегия выполнения PowerShell в Windows

Если PowerShell сообщает "Невозможно загрузить файл... выполнение скриптов запрещено на этой системе":

```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```
