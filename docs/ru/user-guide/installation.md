## Способ установки

### Способ 1: Установка с помощью pip

```bash
# Установка ErisPulse
pip install ErisPulse

# Обновление до последней версии
pip install ErisPulse --upgrade
```

### Способ 2: Установка с помощью uv (рекомендуется)

uv — это более быстрый набор инструментов для Python, рекомендуемый для среды разработки.

#### Установка uv

```bash
# Установка uv через pip
pip install uv

# Проверка установки
uv --version
```

#### Создание виртуального окружения

```bash
# Создание директории проекта
mkdir my_bot && cd my_bot

# Установка Python 3.12
uv python install 3.12

# Создание виртуального окружения
uv venv
```

#### Активация виртуального окружения

```bash
# Windows
.venv\Scripts\activate

# Linux/Mac
source .venv/bin/activate
```

#### Установка ErisPulse

```bash
# Установка ErisPulse
uv pip install ErisPulse --upgrade

## Часто задаваемые вопросы

### Ошибка установки

1. Проверьте версию Python (должна быть >= 3.10; рекомендуется 3.10 – 3.13)
2. Попробуйте использовать `uv pip install ErisPulse` вместо `pip install`
3. Если появляется ошибка разрешений, попробуйте `pip install --user ErisPulse` или используйте виртуальное окружение
4. Если вы работаете за корпоративным прокси и получаете ошибку сертификата SSL, попробуйте `pip install --trusted-host pypi.org --trusted-host files.pythonhosted.org ErisPulse`
5. Убедитесь, что соединение с сетью установлено и репозитории pip доступны

### Ошибка конфигурации

1. Проверьте правильность синтаксиса файла `config.toml` (формат TOML чувствителен к отступам и кавычкам)
2. Убедитесь, что все обязательные параметры конфигурации заполнены
3. Посмотрите логи в терминале для получения подробной информации об ошибке
4. Используйте `epsdk init` для пересоздания файла конфигурации

### Ошибка установки модуля

1. Убедитесь, что в имени модуля нет опечаток (с учетом регистра)
2. Проверьте подключение к сети
3. Используйте `epsdk list-remote` для просмотра списка доступных модулей
4. Убедитесь, что модуль совместим с вашей текущей версией SDK
