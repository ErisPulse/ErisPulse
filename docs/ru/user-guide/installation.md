# Справочник по установке

> Эта статья представляет собой **полный справочник** по способам установки (pip / uv / Docker / устранение неполадок).  
> Если вы хотите просто быстро запустить, [5-минутный краткий старт](../quick-start.md) уже охватывает самый простой процесс.

## Требования к системе

- Python 3.10 или выше
- pip или uv (рекомендуется)
- Достаточное свободное место на диске (не менее 100 МБ)

## Способы установки

### Способ 1: Установка с помощью pip

```bash
# Установка ErisPulse
pip install ErisPulse

# Обновление до последней версии
pip install ErisPulse --upgrade
```

### Способ 2: Установка с помощью uv (рекомендуется)

uv — это более быстрый инструмент для Python, рекомендуемый для среды разработки.

#### Установка uv

```bash
# Установка uv с помощью pip
pip install uv

# Проверка установки
uv --version
```

#### Создание виртуальной среды

```bash
# Создание каталога проекта
mkdir my_bot && cd my_bot

# Установка Python 3.12
uv python install 3.12

# Создание виртуальной среды
uv venv
```

#### Активация виртуальной среды

```bash
# Windows
.venv\Scripts\activate

# Linux/Mac
source .venv/bin/activate
```

#### Установка ErisPulse

```bash
# Установка ErisPulse
uv pip install ErisPulse --upgrade
```

## Проверка установки

### Проверка установки

```bash
# Проверка версии ErisPulse
epsdk --version
```

### Запуск теста

```bash
# Запуск проекта
epsdk run main.py
```

Если вы видите подобный вывод, значит установка прошла успешно:

```
[INFO] Инициализация ErisPulse...
[INFO] Адаптер загружен: Yunhu
[INFO] Модуль загружен: MyModule
[INFO] Инициализация ErisPulse завершена
```

## Распространённые проблемы

### Ошибка установки

1. Проверьте, что версия Python >= 3.10 (рекомендуется 3.10 - 3.13)
2. Попробуйте использовать `uv pip install ErisPulse` вместо `pip install`
3. Если возникает ошибка прав доступа, попробуйте `pip install --user ErisPulse` или используйте виртуальную среду
4. Если при работе за корпоративным прокси возникает ошибка SSL-сертификата, попробуйте `pip install --trusted-host pypi.org --trusted-host files.pythonhosted.org ErisPulse`
5. Убедитесь, что сетевое подключение работает нормально, и репозиторий pip доступен

### Ошибка конфигурации

1. Проверьте синтаксис файла `config.toml` (TOML-формат чувствителен к отступам и кавычкам)
2. Убедитесь, что все необходимые параметры конфигурации заполнены
3. Посмотрите логи терминала для получения подробной информации об ошибках
4. Используйте `epsdk init`, чтобы пересоздать файл конфигурации

### Ошибка установки модуля

1. Убедитесь, что имя модуля написано правильно (регистр важен)
2. Проверьте сетевое подключение
3. Используйте `epsdk list-remote`, чтобы посмотреть список доступных модулей
4. Убедитесь, что модуль совместим с текущей версией SDK

### Выполнение политики PowerShell в Windows

Если PowerShell выдаёт сообщение "Невозможно загрузить файл... так как выполнение скриптов на этой системе запрещено":

```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```
