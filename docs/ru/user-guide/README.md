## Быстрый справочник

### Часто используемые команды

| Команда | Описание | Пример |
|---------|-----------|--------|
| `epsdk init` | Инициализация проекта | `epsdk init -q -n my_bot` |
| `epsdk install` | Установка модуля/адаптера | `epsdk install Yunhu` |
| `epsdk run` | Запуск проекта | `epsdk run main.py --reload` |
| `epsdk list` | Перечислить установленные модули | `epsdk list -t modules` |
| `epsdk upgrade` | Обновление модуля | `epsdk upgrade Yunhu` |

### Расположение общих настроек

| Параметр конфигурации | Описание |
|-----------------------|----------|
| `[ErisPulse.server]` | Конфигурация сервера (хост, порт) |
| `[ErisPulse.logger]` | Конфигурация логирования (уровень, файл вывода) |
| `[ErisPulse.framework]` | Конфигурация фреймворка (ленивая загрузка) |
| `[ErisPulse.event.command]` | Конфигурация событий команд (префикс) |
| `[Имя_адаптера]` | Специфическая конфигурация для каждого адаптера |

### Структура каталога проекта

```text
project/
├── config/
│   └── config.toml          # Файл конфигурации проекта
├── main.py                  # Файл входа в проект
└── requirements.txt          # Список зависимостей
```

## Режим разработки

### Режим перезагрузки (Hot Reload)

Используйте этот режим при разработке для автоматической перезагрузки кода после изменений:

```bash
epsdk run main.py --reload
```

### Обычный режим работы

Для производственной среды используйте обычный режим работы:

```bash
epsdk run main.py
```

## Частые задачи

### Установка нового модуля

```bash
# Установка из удаленного репозитория
epsdk install Yunhu Weather

# Установка из локального каталога
epsdk install ./my-module

# Интерактивная установка
epsdk install
```

### Просмотр доступных модулей

```bash
# Вывести все модули
epsdk list

# Вывести только адаптеры
epsdk list -t adapters

# Вывести только модули
epsdk list -t modules

# Вывести удаленно доступные модули
epsdk list-remote
```

### Обновление модулей

```bash
# Обновить указанный модуль
epsdk upgrade Yunhu

# Обновить все модули
epsdk upgrade
```

### Удаление модулей

```bash
# Удалить указанный модуль
epsdk uninstall Yunhu

# Удалить несколько модулей
epsdk uninstall Yunhu Weather
```
