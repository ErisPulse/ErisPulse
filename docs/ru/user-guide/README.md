## Краткая справка

### Распространенные команды

| Команда | Описание |
|------|------|
| `epsdk init` | Инициализация проекта (режим `-q`, режим `-n` для указания имени) |
| `epsdk install <имя пакета>` | Установка модуля/адаптера (без параметров — интерактивный режим) |
| `epsdk run main.py` | Запуск проекта (режим `--reload` с автоперезагрузкой) |
| `epsdk list` | Вывод списка установленных модулей/адаптеров |
| `epsdk upgrade <имя пакета>` | Обновление модуля/адаптера |
| `epsdk doctor` | Диагностика среды (Python/бэкенд/конфигурация/связь с PyPI) |

> Полный список команд и описание параметров см. в разделе [Справка по CLI-командам](cli-reference.md).

### Расположение распространенных настроек

| Параметр | Описание | Подробнее |
|--------|------|------|
| `[ErisPulse.server]` | Настройка сервера (хост, порт) | [Описание конфигурации](configuration.md#серверная-конфигурация) |
| `[ErisPulse.logger]` | Настройка логирования (уровень, файл вывода) | [Описание конфигурации](configuration.md#настройка-логирования) |
| `[ErisPulse.framework]` | Настройка фреймворка (ленивая загрузка) | [Описание конфигурации](configuration.md#конфигурация-фреймворка) |
| `[ErisPulse.event.command]` | Настройка командных событий (префикс) | [Описание конфигурации](configuration.md#настройка-событий) |
| `[Название_адаптера]` | Специфичные настройки адаптера | [Руководство по особенностям платформ](../platform-guide/) |
