## Быстрая справка

### Часто используемые команды

| Команда | Описание |
|------|------|
| `epsdk init` | Инициализация проекта (`-q` быстрый режим, `-n` указание имени) |
| `epsdk install <имя_пакета>` | Установка модуля/адаптера (без параметров переходит в интерактивный режим) |
| `epsdk config <имя>` | Интерактивная настройка декларативных параметров адаптера/модуля |
| `epsdk run main.py` | Запуск проекта (`--reload` режим горячей перезагрузки) |
| `epsdk list` | Список установленных модулей/адаптеров |
| `epsdk upgrade <имя_пакета>` | Обновление модуля/адаптера |
| `epsdk doctor` | Диагностика среды (Python/бэкенд/конфигурация/доступность PyPI) |

> Полный список команд и описание параметров можно найти в [Справке по командной строке](cli-reference.md).

### Распространённые места конфигурации

| Параметр | Описание | См. также |
|--------|------|------|
| `[ErisPulse.server]` | Конфигурация сервера (хост, порт) | [Описание конфигурационного файла](configuration.md#серверная-конфигурация) |
| `[ErisPulse.logger]` | Конфигурация логирования (уровень, файл вывода) | [Описание конфигурационного файла](configuration.md#конфигурация-логирования) |
| `[ErisPulse.framework]` | Конфигурация фреймворка (ленивая загрузка) | [Описание конфигурационного файла](configuration.md#конфигурация-фреймворка) |
| `[ErisPulse.event.command]` | Конфигурация событий команд (префикс) | [Описание конфигурационного файла](configuration.md#конфигурация-событий) |
| `[имя_адаптера]` | Специфичная конфигурация для каждого адаптера | [Руководство по платформенным особенностям](../platform-guide/) |
