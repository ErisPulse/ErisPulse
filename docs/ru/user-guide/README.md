## Быстрый справочник

### Часто используемые команды

| Команда | Описание |
|---------|----------|
| `epsdk init` | Инициализация проекта (`-q` быстрый режим, `-n` указание имени) |
| `epsdk install <имя_пакета>` | Установка модуля/адаптера (без параметров — переход в интерактивный режим) |
| `epsdk run main.py` | Запуск проекта (`--reload` режим горячей перезагрузки) |
| `epsdk list` | Перечисление установленных модулей/адаптеров |
| `epsdk upgrade <имя_пакета>` | Обновление модуля/адаптера |

> Полный список команд и описание параметров см. в [Справочнике по командам CLI](cli-reference.md).

### Расположение общих настроек

| Параметр конфигурации | Описание | Ссылка |
|-----------------------|----------|--------|
| `[ErisPulse.server]` | Конфигурация сервера (хост, порт) | [Описание конфигурационных файлов](configuration.md#настройки_сервера) |
| `[ErisPulse.logger]` | Конфигурация логирования (уровень, файл вывода) | [Описание конфигурационных файлов](configuration.md#настройки_логирования) |
| `[ErisPulse.framework]` | Конфигурация фреймворка (ленивая загрузка) | [Описание конфигурационных файлов](configuration.md#настройки_фреймворка) |
| `[ErisPulse.event.command]` | Конфигурация событий команд (префикс) | [Описание конфигурационных файлов](configuration.md#настройки_событий) |
| `[имя_адаптера]` | Специфическая конфигурация для каждого адаптера | [Руководство по платформенным особенностям](../platform-guide/) |
