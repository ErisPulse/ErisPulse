## Быстрая справка

### Часто используемые команды

| Команда | Описание |
|---------|----------|
| `epsdk init` | Инициализация проекта (`-q` быстрый режим, `-n` указать имя) |
| `epsdk install <имя_пакета>` | Установка модуля/адаптера (без параметров запускает интерактивный режим) |
| `epsdk config <имя>` | Интерактивная конфигурация декларативных параметров адаптера/модуля |
| `epsdk run main.py` | Запуск проекта (`--reload` режим горячей перезагрузки) |
| `epsdk list` | Список установленных модулей/адаптеров |
| `epsdk upgrade <имя_пакета>` | Обновление модуля/адаптера |
| `epsdk doctor` | Диагностика окружения (Python/бэкенд/конфигурация/доступность PyPI) |

> Полный список команд и описание параметров можно найти в [Справке по командной строке](cli-reference.md).

| Параметр | Описание | См. также |

| `[ErisPulse.logger]` | Конфигурация логирования (уровень, файл вывода) | [Описание файла конфигурации](configuration.md#конфигурация-логирования) |
| `[ErisPulse.framework]` | Конфигурация фреймворка (ленивая загрузка) | [Описание файла конфигурации](configuration.md#конфигурация-фреймворка) |

| `[имя_адаптера]` | Специфичная конфигурация каждого адаптера | [Руководство по особенностям платформы](../platform-guide/) |
