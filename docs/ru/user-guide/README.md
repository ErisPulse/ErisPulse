## Быстрая справка

### Распространённые команды

| Команда | Описание |
|------|------|
| `epsdk init` | Инициализация проекта (режим быстрого выполнения `-q`, указание имени `-n`) |
| `epsdk install <имя_пакета>` | Установка модуля/адаптера (без аргументов переключение в интерактивный режим) |
| `epsdk run main.py` | Запуск проекта (режим автоматической перезагрузки `--reload`) |
| `epsdk list` | Вывод списка установленных модулей/адаптеров |
| `epsdk upgrade <имя_пакета>` | Обновление модуля/адаптера |
| `epsdk doctor` | Диагностика окружения (Python/Backend/Настройки/Связь с PyPI) |

> Полный список команд и описание параметров см. в [Справке по CLI](docs/ru/cli-reference.md).

| Параметр | Описание | Подробнее |
|--------|------|------|
| `[ErisPulse.server]` | Настройка сервера (хост, порт) | [Справка по конфигурации файла](docs/ru/configuration.md#настройка-сервера) |
| `[ErisPulse.logger]` | Настройка логов (уровень, файл вывода) | [Справка по конфигурации файла](docs/ru/configuration.md#настройка-логов) |
| `[ErisPulse.framework]` | Настройка фреймворка (ленивая загрузка) | [Справка по конфигурации файла](docs/ru/configuration.md#настройка-фреймворка) |
| `[ErisPulse.event.command]` | Настройка событий команд (префикс) | [Справка по конфигурации файла](docs/ru/configuration.md#настройка-событий) |
| `[Имя_адаптера]` | Специфические настройки конкретного адаптера | [Руководство по платформенным особенностям](../platform-guide/) |
