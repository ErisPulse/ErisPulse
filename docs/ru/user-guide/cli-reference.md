# Справочник команд CLI

Инструмент командной строки ErisPulse (`epsdk`) предоставляет функции управления проектами и пакетами.

> **Примечание:** Параметры всех команд можно посмотреть с помощью `epsdk <команда> --help`.

---

## Команды управления пакетами

| Команда | Алиас | Параметры | Описание |
|------|------|------|------|
| `install` | `i`, `add` | `[пакет]... [--upgrade/-U] [--pre] [-e ПУТЬ] [--user] [--no-deps] [-t КАТАЛОГ] [--index-url URL] [--extra-index-url URL] [--no-cache-dir] [-r ФАЙЛ] [-c ФАЙЛ] [--force-reinstall] [--ignore-installed] [--compile/--no-compile] [--prefix КАТАЛОГ] [--src КАТАЛОГ] [--config-settings НАСТРОЙКИ] [--no-binary ФОРМАТ] [--only-binary ФОРМАТ] [--prefer-binary] [--build-isolation/--no-build-isolation] [--upgrade-strategy {eager,only-if-needed,to-satisfy-only}] [--break-system-packages] [--no-uv]` | Установка модуля/адаптера |

### install

Установка пакета модуля или адаптера ErisPulse. Если пакет не указан, запускается интерактивное окно установки.

**Алиасы:** `i`, `add`

**Параметры:**

| Параметр | Краткий | Описание |
|------|--------|------|
| `[пакет]...` | | Имя пакета для установки, можно указать несколько |
| `--upgrade` | `-U` | Обновление до последней версии при установке |
| `--pre` | | Разрешить установку предрелизных версий |
| `--editable` | `-e` | Установка в режиме редактирования (требует указания пути) |
| `--user` | | Установка в каталог site-packages пользователя |
| `--no-deps` | | Не устанавливать зависимости |
| `--target` | `-t` | Установка в указанный каталог |
| `--index-url` | | Указание URL-адреса зеркала PyPI |
| `--extra-index-url` | | Дополнительный URL-адрес зеркала PyPI (можно указать несколько) |
| `--no-cache-dir` | | Отключение кэша |
| `--requirement` | `-r` | Установка из файла requirements |
| `--constraint` | `-c` | Установка из файла constraint |
| `--force-reinstall` | | Принудительная переустановка |
| `--ignore-installed` | | Игнорировать уже установленные пакеты |
| `--compile` | | Компиляция .pyc файлов после установки |
| `--no-compile` | | Не компилировать .pyc файлы после установки |
| `--prefix` | | Установка в указанный префиксный каталог |
| `--src` | | Используемый каталог исходного кода при установке в режиме редактирования |
| `--config-settings` | | Передача настроек в сборочный бэкенд (можно указать несколько) |
| `--no-binary` | | Ограничение использования бинарных пакетов (формат как `:all:`) |
| `--only-binary` | | Ограничение использования только бинарных пакетов (формат как `:all:`) |
| `--prefer-binary` | | Предпочтение бинарных пакетов |
| `--build-isolation` | | Включение изоляции сборки |
| `--no-build-isolation` | | Отключение изоляции сборки |
| `--upgrade-strategy` | | Стратегия обновления: `eager`, `only-if-needed`, `to-satisfy-only` |
| `--break-system-packages` | | Разрешить изменение системных пакетов Python |
| `--no-uv` | | Использование pip вместо uv |

**Примеры:**

```bash
# Установка одного модуля
epsdk install Weather

# Установка нескольких модулей
epsdk install Yunhu Weather

# Установка с обновлением из зеркала
epsdk install Weather -U --index-url https://pypi.tuna.tsinghua.edu.cn/simple

# Установка в режиме редактирования (режим разработки)
epsdk install -e ./my-adapter
```

### uninstall

Удаление установленного модуля или адаптера ErisPulse. Если пакет не указан, запускается интерактивное окно удаления.

**Алиасы:** `rm`, `remove`

**Параметры:**

| Параметр | Описание |
|------|------|
| `<пакет>...` | Имя пакета для удаления, можно указать несколько |
| `--no-uv` | Использование pip вместо uv |

**Примеры:**

```bash
# Удаление одного модуля
epsdk uninstall Weather

# Удаление нескольких модулей
epsdk uninstall Yunhu Weather
```

### upgrade

Обновление установленных компонентов ErisPulse. Если пакет не указан, запускается интерактивное обновление всех.

**Алиасы:** `up`

**Параметры:**

| Параметр | Краткий | Описание |
|------|--------|------|
| `[пакет]...` | | Имя пакета для обновления, можно указать несколько |
| `--force` | `-f` | Принудительное обновление, без подтверждения |
| `--pre` | | Разрешить обновление до предрелизных версий |
| `--no-uv` | | Использование pip вместо uv |

**Примеры:**

```bash
# Обновление всех пакетов
epsdk upgrade

# Обновление указанного пакета
epsdk upgrade Weather

# Принудительное обновление (без подтверждения)
epsdk upgrade -f
```

### self-update

Обновление самого SDK ErisPulse до последней версии.

**Алиасы:** `su`, `update`

**Параметры:**

| Параметр | Краткий | Описание |
|------|--------|------|
| `[версия]` | | Указание целевой версии для обновления |
| `--pre` | | Разрешить обновление до предрелизных версий |
| `--force` | `-f` | Принудительное обновление, без подтверждения |
| `--no-uv` | | Использование pip вместо uv |

**Примеры:**

```bash
# Обновление до последней стабильной версии
epsdk self-update

# Обновление до указанной версии
epsdk self-update 1.2.3

# Разрешить предрелизные версии
epsdk self-update --pre

# Принудительное обновление
epsdk self-update -f
```

### list

Вывод списка установленных модулей и адаптеров ErisPulse.

**Параметры:**

| Параметр | Краткий | Описание |
|------|--------|------|
| `--type` | `-t` | Указание типа: `modules`, `adapters`, `all` (по умолчанию) |

```bash

epsdk list -o
```

Вывод списка доступных модулей и адаптеров ErisPulse на удаленном репозитории.

**Параметры:**

| Параметр | Краткий | Описание |
|------|--------|------|

| `--refresh` | `-r` | Принудительное обновление кэша списка пакетов |

**Примеры:**


## Команды конфигурации

| Команда | Алиас | Параметры | Описание |
|------|------|------|------|
| `config` | `cfg`, `conf` | `[имя] [--list/-l]` | Интерактивная конфигурация адаптеров/модулей |

### config

Интерактивное заполнение конфигурации адаптеров/модулей с помощью декларативных настроек. Визуальный помощник запускается на основе класса конфигурации (ConfigClass / AccountConfigClass), автоматически генерирует форму и проверяет данные, не требуя ручного редактирования config.toml.

Для адаптеров дополнительно поддерживается управление несколькими учетными записями (бот-аккаунтами): добавление/редактирование/удаление учетных записей, а также включение/отключение.

**Алиасы:** `cfg`, `conf`

**Параметры:**

| Параметр | Краткий | Описание |
|------|--------|------|
| `[имя]` | | Имя цели (название платформы адаптера или модуля), пустое значение для выбора в интерактивном режиме |
| `--list` | `-l` | Вывод только состояния конфигурации всех целей, без запуска помощника |

**Примеры:**

```bash
# Вывод состояния конфигурации всех адаптеров/модулей
epsdk config --list

# Выбор цели для конфигурации
epsdk config

# Конфигурация указанного адаптера
epsdk config yunhu

# Конфигурация указанного модуля
epsdk config MyModule
```

**Описание:**

- Состояние конфигурации делится на четыре категории: `Готово` (проверка пройдена), `Незавершено` (отсутствуют обязательные поля или проверка не пройдена), `Не настроено` (никогда не генерировалось), `Без конфигурации` (цель не декларирует класс конфигурации)
- Значения полей отображаются с указанием источника: уже настроенные значения показываются как `（Текущее:значение）`, ненастраиваемые поля отображают значения по умолчанию схемы `（По умолчанию:значение）` при пустом вводе сохраняется текущее значение
- Ввод значений секретных полей (объявленных как `secret`) не отображается, при нажатии Enter сохраняется предыдущее значение
- В режиме выбора цели после завершения одного помощника обновляется состояние и возвращается в меню выбора, можно последовательно настроить несколько целей, пустой ввод завершает процесс
- При неудачной проверке формы и отказе от повторного ввода текущий помощник завершается без сохранения конфигурации (избегается состояние "включено, но конфигурация не завершена")
- Сохранение сразу записывается в `config/config.toml`, видно в Dashboard и работающем SDK; для применения новых учетных записей в работающем адаптере требуется перезапуск процесса
- `epsdk install` (интерактивная установка) и `epsdk init` при успешной установке адаптера, если обнаружено объявление конфигурации, автоматически запускает этот помощник; при установке через командную строку с указанием имени пакета выводится только подсказка о конфигурации

## Команды управления запуском

> [!TIP]
> `epsdk run` автоматически обнаруживает и использует виртуальное окружение `.venv` в каталоге проекта для запуска бота
> (также можно явно указать интерпретатор через переменную окружения `ERISPULSE_PYTHON`). Команды `epsdk install` /
> `uninstall` / `upgrade` / `list` также применяются к виртуальному окружению проекта.

| Команда | Алиас | Параметры | Описание |
|------|------|------|------|
| `run` | `r` | `[скрипт] [--reload]` | Запуск указанного скрипта или SDK |

### run

Запуск скрипта проекта ErisPulse или запуск SDK. Поддержка режима горячей перезагрузки.

**Алиасы:** `r`

**Параметры:**

| Параметр | Описание |
|------|------|
| `[скрипт]` | Имя файла скрипта для запуска, если не указан, запускается SDK |
| `--reload` | Включение режима горячей перезагрузки, автоматический перезапуск при изменении файлов |

**Примеры:**

```bash
# Прямой запуск SDK
epsdk run

# Запуск указанного файла скрипта
epsdk run main.py

# Горячая перезагрузка (перезапуск при изменении файлов)
epsdk run main.py --reload

# Горячая перезагрузка SDK
epsdk run --reload
```

## Команды управления проектом

| Команда | Алиас | Параметры | Описание |
|------|------|------|------|
| `init` | — | `[путь] [--project-name/-n <имя>] [--path <каталог>] [--quick/-q] [--force/-f] [--here] [--no-uv] [--no-venv]` | Инициализация проекта ErisPulse |
| `create` | — | `{module,adapter} [--name/-n <имя>] [--description/-d <описание>] [--author/-a <автор>] [--email/-e <почта>] [--homepage <сайт>] [--output/-o <каталог>] [--force/-f]` | Создание шаблона модуля/адаптера |

### init

Инициализация нового проекта ErisPulse. Поддержка интерактивного и быстрого режимов, начиная с версии 2.8.4, создается `pyproject.toml` (список зависимостей), опционально создается виртуальное окружение `.venv` и устанавливается фреймворк с адаптерами, поддерживается **указание произвольного каталога**.

**Параметры:**

| Параметр | Краткий | Описание |
|------|--------|------|
| `[путь]` | | Целевой путь (может включать родительский каталог, например `../apps/mybot`; имя без пути эквивалентно `--project-name`) |
| `--project-name` | `-n` | Имя проекта |
| `--path` | | Родительский каталог проекта (в сочетании с `-n` указывает место создания) |
| `--quick` | `-q` | Быстрый режим, пропуск интерактивного гида (по умолчанию создается `.venv` и устанавливаются зависимости) |
| `--force` | `-f` | Принудительное перезаписывание существующих файлов конфигурации |
| `--here` | | Инициализация в текущем каталоге, без создания подкаталога |
| `--no-uv` | | Использование pip вместо uv |
| `--no-venv` | | Пропуск создания виртуального окружения и установки зависимостей |

**Примеры:**

```bash
# Интерактивная инициализация
epsdk init

# Быстрая инициализация (создание my_bot/ в текущем каталоге, с pyproject.toml и .venv)
epsdk init -q -n my_bot

# Инициализация в произвольном каталоге (../apps/mybot)
epsdk init ../apps/mybot

# Комбинация родительского каталога и имени проекта
epsdk init -n my_bot --path ../apps

# Принудительная перезапись существующих файлов конфигурации
epsdk init -f

# Инициализация в текущем каталоге
epsdk init --here -n my_bot

# Создание структуры проекта без виртуального окружения
epsdk init --no-venv -n my_bot
```

Результат инициализации: `main.py`, `pyproject.toml` (список зависимостей), `config/config.toml` + `config.full.example`, `config/ssl/`, `logs/`, `.gitignore`, `README.md`; при создании виртуального окружения дополнительно создается `.venv` и устанавливаются `erispulse` и выбранные адаптеры.

> [!WARNING]
> **Не используйте `uv run epsdk run` для запуска бота**. `uv run` создает одноразовое изолированное окружение в каталоге без `pyproject.toml` — пакеты, установленные через `epsdk install`, не сохраняются. Используйте `epsdk run` в каталоге проекта (автоматически использует `.venv` проекта), или активируйте виртуальное окружение перед запуском.

### create

Создание шаблона модуля или адаптера ErisPulse.

**Параметры:**

| Параметр | Краткий | Описание |
|------|--------|------|
| `{module,adapter}` | | Тип создаваемого проекта: `module` или `adapter` |
| `--name` | `-n` | Имя проекта (в PascalCase) |
| `--description` | `-d` | Описание проекта |
| `--author` | `-a` | Имя автора |
| `--email` | `-e` | Email автора |
| `--homepage` | | URL-адрес сайта проекта |
| `--output` | `-o` | Каталог вывода (по умолчанию текущий каталог) |
| `--force` | `-f` | Принудительная перезапись существующего каталога |
| `--local` | | Создание локального плагина (доступно только для `module`): генерация структуры `plugins/<имя>/`, установка без пакетирования |

**Примеры:**

```bash
# Интерактивное создание (вывод гида выбора типа и заполнения информации)
epsdk create

# Создание проекта Module
epsdk create module -n MyModule

# Создание локального плагина (в каталоге `plugins/`, автоматически обнаруживается при запуске, поддержка горячей перезагрузки)
epsdk create module -n MyModule --local

# Создание проекта Adapter
epsdk create adapter -n MyAdapter

# Полные параметры
epsdk create module -n MyModule -d "Описание модуля" -a "Автор" -e "mail@example.com"

# Указание каталога вывода
epsdk create module -n MyModule -o ./projects

# Принудительная перезапись существующего каталога
epsdk create module -n MyModule -f
```

Просмотр текущего языка CLI, вывод списка поддерживаемых языков, смена языка отображения. Если параметр не указан, запускается интерактивное окно выбора.

```bash
epsdk i18n
```

| `--force` | | Принудительная перезапись существующих файлов |
| `--adapters-only` | | Генерация только для адаптеров |
| `--modules-only` | | Генерация только для модулей |

> **Примечание:** Параметры `--adapters-only` и `--modules-only` взаимоисключаются, при одновременном использовании применяется последний.

**Примеры:**

```bash
# Генерация типовых аннотаций для всех установленных модулей и адаптеров
epsdk types

# Только для адаптеров
epsdk types --adapters-only

# Вывод в указанный каталог
epsdk types -o ./typings

# Принудительная перезапись файлов
epsdk types --force
```

## Диагностика окружения

### doctor

> [!NOTE]
> Эта команда требует ErisPulse **2.7.0+**.

Диагностика текущего окружения CLI, вывод отчета о состоянии. Используется для устранения проблем типа "почему не устанавливается / не подключается".

| Параметр | Описание |
|------|------|
| `--verbose` | Отображение подробной информации о диагностике |

**Проверяемые элементы:**
- **Python**: версия и путь интерпретатора
- **Установщик**: используется `uv` или `pip`
- **Целевой интерпретатор**: окружение, в которое устанавливаются пакеты
- **Конфигурационный файл**: наличие `config/config.toml`
- **Доступность PyPI**: возможность подключения к PyPI (и отображение количества обнаруженных компонентов)
- **Системный прокси**: обнаружение прокси-сервера

```bash
# Диагностика среды
epsdk doctor

# Использование алиаса
epsdk diag
```

## Интерактивная установка

Запуск `epsdk install` без указания пакета приводит к интерактивной установке:

```bash
epsdk install
```

Интерактивное окно предоставляет:
1. Выбор адаптера
2. Выбор модуля
3. Пользовательская установка

## Распространенные сценарии

### Установка модуля

```bash
# Установка одного модуля
epsdk install Weather

# Установка нескольких модулей
epsdk install Yunhu Weather

# Обновление модуля
epsdk install Weather -U
```

### Вывод компонентов

```bash
# Вывод всех компонентов
epsdk list

# Только адаптеры
epsdk list -t adapters

# Только обновляемые компоненты
epsdk list -o

# Просмотр доступных компонентов
epsdk list-remote
```

### Удаление компонентов

```bash
# Удаление одного компонента
epsdk uninstall Weather

# Удаление нескольких компонентов
epsdk uninstall Yunhu Weather
```

### Настройка компонентов

```bash
# Просмотр состояния конфигурации
epsdk config --list

# Выбор цели для настройки
epsdk config

# Настройка указанного адаптера
epsdk config yunhu
```

### Обновление компонентов

```bash
# Обновление всех компонентов
epsdk upgrade

# Обновление указанного компонента
epsdk upgrade Weather

# Принудительное обновление
epsdk upgrade -f
```

### Запуск проекта

```bash
# Обычный запуск
epsdk run main.py

# Режим горячей перезагрузки
epsdk run main.py --reload
```

### Смена языка

```bash
# Интерактивный выбор языка
epsdk i18n

# Прямая смена на английский
epsdk i18n en

# Вывод поддерживаемых языков
epsdk i18n --list
```

### Генерация типовых аннотаций

```bash
# Генерация всех типовых аннотаций
epsdk types

# Только для модулей
epsdk types --modules-only
```

### Инициализация проекта

```bash
# Интерактивная инициализация
epsdk init

# Быстрая инициализация
epsdk init -q -n my_bot
```

### Создание шаблона

```bash
# Интерактивное создание (вывод гида выбора типа и заполнения информации)
epsdk create

# Прямое создание проекта Module
epsdk create module -n MyModule

# Прямое создание проекта Adapter
epsdk create adapter -n MyAdapter

# Полные параметры
epsdk create module -n MyModule -d "Описание модуля" -a "Автор" -e "mail@example.com"

# Принудительная перезапись существующего каталога
epsdk create module -n MyModule -f
```
