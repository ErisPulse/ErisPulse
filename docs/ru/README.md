# Документация ErisPulse

ErisPulse — это расширяемая, многофункциональная платформа для обработки сообщений, поддерживающая взаимодействие с различными платформами через адаптеры и предоставляющая гибкую систему модулей для расширения функциональности.

> **Впервые используете?** Начните с [5-минутного краткого руководства](docs/ru/quick-start.md) — от установки до запуска первого бота, шаг за шагом.

## Способы разработки

ErisPulse поддерживает два способа разработки:

- **Разработка модуля (рекомендуется):** Создание отдельного пакета модуля, устанавливаемого через менеджер пакетов, удобен для распространения и управления.
- **Встраиваемая разработка:** Непосредственное написание обработчиков в проекте, подходит для быстрой прототипизации. Подробнее см. [Краткое руководство](docs/ru/quick-start.md).
