# Документация ErisPulse

ErisPulse — это расширяемая многоплатформенная система обработки сообщений, поддерживающая взаимодействие с различными платформами через адаптеры и предоставляющая гибкую систему модулей для расширения функциональности.

> **Впервые используете?** Просто прочитайте [Быстрый старт за 5 минут](docs/ru/quick-start.md) — от установки до запуска первого бота, всё в одном руководстве.

## Способы разработки

ErisPulse поддерживает два способа разработки:

- **Разработка модулей (рекомендуется)**: создание отдельных пакетов модулей, устанавливаемых через менеджер пакетов, удобно для распространения и управления.
- **Встраиваемая разработка**: непосредственное написание обработчиков в проекте, подходит для быстрой разработки прототипов. Подробнее см. [Быстрый старт](docs/ru/quick-start.md).
