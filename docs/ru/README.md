# Документация ErisPulse

ErisPulse — это фреймворк асинхронных модульных роботов на основе событий. Написанная один раз бизнес-логика может быть развернута на QQ, Telegram, Kook, Yunhu и других платформах через адаптеры. Встроенные плагины, горячая перезагрузка и полный набор инструментов для разработки — всё это работает из коробки.

> **Первый раз?** Просто посмотрите [5-минутное краткое руководство](quick-start.md) — от установки до запуска первого робота, всё в одном месте.

## Способы разработки

ErisPulse поддерживает два способа разработки:

- **Разработка модулей (рекомендуется):** Создание отдельного пакета модуля, установка через менеджер пакетов, удобно для распространения и управления.
- **Встраиваемая разработка:** Прямое написание обработчиков в проекте, подходит для быстрого прототипирования. Подробнее см. [Краткое руководство](quick-start.md).
