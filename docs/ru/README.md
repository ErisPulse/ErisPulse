# Документация ErisPulse

ErisPulse — это масштабируемый многофункциональный фреймворк для обработки сообщений, поддерживающий взаимодействие с различными платформами через адаптеры и предоставляющий гибкую систему модулей для расширения функциональности.

> **Впервые используете?** Просто посмотрите [Быстрый старт за 5 минут](docs/ru/quick-start.md) — от установки до запуска первого бота, всё по порядку.
>
> Непонятные термины? Посмотрите [Словарь терминов](terminology.md).

## Способы разработки

ErisPulse поддерживает два способа разработки:

- **Разработка модулей (рекомендуется)**: Создание отдельного пакета модуля, устанавливаемого через менеджер пакетов, удобного для распространения и управления.
- **Встраиваемая разработка**: Прямое написание обработчиков в проекте, подходит для быстрой разработки прототипов. Подробнее см. [Быстрый старт](docs/ru/quick-start.md).
