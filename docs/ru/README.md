# Документация ErisPulse

ErisPulse — это расширяемая многофункциональная система обработки сообщений, поддерживающая взаимодействие с различными платформами через адаптеры и предоставляющая гибкую систему модулей для расширения функциональности.

> **Впервые используете?** Просто посмотрите [5-минутный краткий старт](docs/ru/quick-start.md) — от установки до запуска первого бота, все шаги описаны.

> Не понимаете термин? Посмотрите [Словарь терминов](terminology.md).

## Способы разработки

ErisPulse поддерживает два способа разработки:

- **Разработка модулей (рекомендуется):** Создание отдельного пакета модуля, устанавливаемого через менеджер пакетов, удобно для распространения и управления.
- **Встраиваемая разработка:** Прямое написание обработчиков в проекте, подходит для быстрого прототипирования. Подробнее см. [Краткий старт](docs/ru/quick-start.md).
