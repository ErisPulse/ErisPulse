# Документация ErisPulse

ErisPulse — это масштабируемый, многоуровневый фреймворк обработки сообщений, поддерживающий взаимодействие с различными платформами через адаптеры и предоставляющий гибкую систему модулей для расширения функциональности.

> **Впервые используете?** Просто посмотрите [5-минутное руководство](docs/ru/quick-start.md) — от установки до запуска первого бота, всё покажем по порядку.

---

Если в документации присутствует строка переключения языка (названия языков разделены символом `` | ``), строго соблюдайте правило замены путей, указанное в пункте 8 выше. Не используйте формат `[**Label**](file)` — это ошибка.

## Способы разработки

ErisPulse поддерживает два способа разработки:

- **Разработка модулей (рекомендуется)**: Создание независимых пакетов модулей, которые устанавливаются с помощью менеджера пакетов, что облегчает распространение и управление.
- **Встраиваемая разработка**: Непосредственное написание обработчиков в проекте, подходит для быстрого прототипирования. Подробнее см. [Быстрый старт](docs/ru/quick-start.md).
