# Документация ErisPulse

ErisPulse — это расширяемая многофункциональная платформа для обработки сообщений, поддерживающая взаимодействие с различными платформами через адаптеры и предоставляющая гибкую систему модулей для расширения функциональности.

> **Впервые используете?** Просто посмотрите [5-минутное краткое руководство](quick-start.md) — от установки до запуска первого бота, всё покажем.

## Способы разработки

ErisPulse поддерживает два способа разработки:

- **Разработка модулей (рекомендуется):** Создание отдельного пакета модуля, устанавливаемого через менеджер пакетов, удобно для распространения и управления.
- **Встраиваемая разработка:** Непосредственное написание обработчиков внутри проекта, подходит для быстрого прототипирования. Подробнее см. [Краткое руководство](quick-start.md).
