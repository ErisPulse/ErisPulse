# Документация ErisPulse

ErisPulse — это фреймворк асинхронного модульного робота, основанный на событиях — бизнес-код пишется один раз, а через адаптеры разворачивается на QQ, Telegram, Kook, Yunhu и других платформах. Система плагинов, горячая перезагрузка и полноценный инструментарий разработчика предоставляются из коробки.

> **Впервые используете?** Просто посмотрите [5-минутное руководство](quick-start.md) — от установки до запуска первого робота, шаг за шагом.

**Таблица отношений между подсистемами**

Когда неясно, какая подсистема отвечает за что, смотрите в эту таблицу:

| Подсистема | Отвечает на вопрос | Односложный мемориал |
|--------|------------|-----------|
| [Коммуникация](advanced/module-communication.md) (module-communication) | Как модули могут вызывать друг друга, как отправлять события в определённый модуль? | Для взаимодействия между модулями используйте `module.call`; если другой модуль объявил `meta.services`, можно вызывать только методы из белого списка |
| [Права доступа](advanced/scope.md) (scope) | Кто может использовать этот модуль, кто может запускать события, какие действия можно выполнять? | Три шлагбаума — привязка модуля, допуск по идентичности, ограничение исходящих действий, всё определяется конфигурацией пользователя |
| [Принадлежность](advanced/ownership.md) (ownership) | Что происходит с подключениями, таймерами, подписками после выгрузки модуля? | Всё, что зарегистрировано, принадлежит, при выгрузке всё автоматически очищается, без висящих ресурсов |

| [Интерактивность](advanced/interaction.md) (interaction) | Как ожидать следующего ответа пользователя, как писать многошаговые сборы? | `wait_reply` — ожидание одного сообщения, `.got()` — цепочка сбора нескольких сообщений, сессионные аренды гарантируют отсутствие конфликтов |
| [Серый деплой](advanced/shadow.md) (shadow) | Как можно протестировать новый модуль, не влияя на рабочую версию? | Серый модуль получает копии данных, исходящие сообщения записываются, но не отправляются реальным пользователям, `promote` — активация по решению человека |
| [Хранилище](advanced/storage-backends.md) (storage-backends) | Где хранятся данные, как можно менять хранилище? | Один и тот же API хранения, переключение между sqlite / mysql / postgres производится через конфигурацию |

## Способы разработки

ErisPulse поддерживает два способа разработки:

- **Разработка модулей** (рекомендуется): создание отдельного пакета модуля, установка через менеджер пакетов, удобно для распространения и управления.
- **Встраиваемая разработка**: непосредственное написание обработчиков в проекте, подходит для быстрой разработки прототипа. Подробнее см. [5-минутное руководство](quick-start.md).
