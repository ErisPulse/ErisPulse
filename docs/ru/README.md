# Документация ErisPulse

ErisPulse — это расширяемая многофункциональная платформа для обработки сообщений, поддерживающая взаимодействие с различными платформами через адаптеры и предоставляющая гибкую систему модулей для расширения функциональности.

> **Впервые с ней?** Начните с [Быстрого старта за 5 минут](quick-start.md) — от установки до запуска первого бота, все шаги объединены.

---

## Способы разработки

ErisPulse поддерживает два способа разработки:

- **Разработка модулей (рекомендуется)**: Создание отдельных пакетов модулей, которые устанавливаются через менеджер пакетов, удобно для распространения и управления.
- **Встраиваемая разработка**: Прямое написание обработчиков в проекте, подходит для быстрых прототипов. Подробнее см. [Быстрый старт](quick-start.md).
