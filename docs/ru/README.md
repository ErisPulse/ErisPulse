# Документация ErisPulse

ErisPulse — это расширяемая многофункциональная система обработки сообщений, поддерживающая взаимодействие с различными платформами через адаптеры и предоставляющая гибкую систему модулей для расширения функциональности.

> **Впервые используете?** Начните с [5-минутного краткого руководства](docs/ru/quick-start.md) — от установки до запуска первого бота, пройдите все этапы.

## Способы разработки

ErisPulse поддерживает два способа разработки:

- **Разработка модулей (рекомендуется):** Создание отдельного пакета модуля, который устанавливается через менеджер пакетов, удобно для распространения и управления.
- **Встраиваемая разработка:** Написание обработчиков непосредственно в проекте, подходит для быстрого прототипирования. Подробнее в [Кратком руководстве](docs/ru/quick-start.md).
