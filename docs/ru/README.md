# Документация ErisPulse

ErisPulse — это масштабируемый, многофункциональный фреймворк для обработки сообщений, поддерживающий взаимодействие с различными платформами через адаптеры и предоставляющий гибкую систему модулей для расширения функциональности.

> **Впервые используете?** Посмотрите [5-минутное руководство по запуску](docs/ru/quick-start.md) — от установки до запуска первого бота, шаг за шагом.

---

Выберите соответствующий путь обучения в зависимости от ваших целей. Каждый путь организован от простого к сложному.

Остальные статьи — это справочные материалы для конкретных сценариев использования: читайте их по мере необходимости, в начале каждой статьи указано, когда она может понадобиться.

## Способы разработки

ErisPulse поддерживает два способа разработки:

- **Разработка модулей (рекомендуется):** создание отдельных пакетов модулей, устанавливаемых через менеджер пакетов, удобно для распространения и управления.
- **Встроенная разработка:** прямое написание обработчиков в проекте, подходит для быстрого прототипирования. Подробнее в [Руководстве по запуску](docs/ru/quick-start.md).
