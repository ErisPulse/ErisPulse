# Документация ErisPulse

ErisPulse — это расширяемая многофункциональная платформа обработки сообщений, поддерживающая взаимодействие с различными платформами через адаптеры и предоставляющая гибкую систему модулей для расширения функциональности.

> **Впервые используете?** Начните с [5-минутного краткого руководства](docs/ru/quick-start.md) — от установки до запуска первого бота, все шаги в одном руководстве.

## Способы разработки

ErisPulse поддерживает два способа разработки:

- **Разработка модулями (рекомендуется)**: Создание независимых пакетов модулей, которые устанавливаются через менеджер пакетов, что упрощает распространение и управление.
- **Встраиваемая разработка**: Непосредственное написание процессоров в проекте, подходит для быстрого прототипирования. Подробнее см. [Быстрый старт](quick-start.md).
