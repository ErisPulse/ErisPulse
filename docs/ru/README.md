# Документация ErisPulse

ErisPulse — это фреймворк асинхронных модульных роботов с событийно-ориентированной архитектурой: бизнес-логику пишут один раз, а через адаптеры разворачивают на QQ, Telegram, Kook, Yunhu и других платформах. Встроенные плагины, горячая перезагрузка и полный набор инструментов для разработчиков — всё работает сразу.

> **Впервые?** Начните с [быстрого старта за 5 минут](quick-start.md) — от установки до запуска первого робота.

**Сводная таблица понятий**

Когда вы не понимаете, какой подсистемой управляет каждый компонент, используйте эту таблицу:

| Подсистема | Отвечает на вопрос | Краткий принцип |
|------------|-------------------|-----------------|
| [Коммуникация](advanced/module-communication.md) (module-communication) | Как модули могут вызывать друг друга и как отправлять события? | Для межмодульного взаимодействия используйте `module.call`; если другой модуль объявил `meta.services`, то можно вызывать только методы из белого списка |
| [Права доступа](advanced/scope.md) (scope) | Кто может использовать модуль, кто может запускать события, какие действия разрешены? | Три уровня контроля: привязка модуля, вход по правам, ограничение исходящих действий — всё определяется конфигурацией пользователя |
| [Принадлежность](advanced/ownership.md) (ownership) | Что происходит с подключениями, таймерами и подписками после выгрузки модуля? | Всё, что зарегистрировано, принадлежит, при выгрузке — всё очищается, не остаётся "висячих" ресурсов |
| [Ленивая загрузка и сон](advanced/lazy-loading.md) (lazy-loading) | Когда модуль загружается и куда переходит в состоянии бездействия? | Модуль активируется при использовании (`activate_on`), а в состоянии бездействия переходит в сон (`dormant_after`) |
| [Интерактивность](advanced/interaction.md) (interaction) | Как ожидать следующего ответа пользователя и как писать многошаговые диалоги? | `wait_reply` ждёт одно сообщение, `.got()` — цепочку, сессии защищены от конфликтов |
| [Серый / теневой](advanced/shadow.md) (shadow) | Как тестировать новую версию модуля без влияния на продакшен? | Теневой модуль получает копию, исходящие сообщения записываются, а `promote` переводит в продакшен только после подтверждения |
| [Хранилище](advanced/storage-backends.md) (storage-backends) | Где хранятся данные и как менять хранилище? | Одинаковый API хранения, переключение между sqlite / mysql / postgres настраивается в конфигурации |

## Способы разработки

ErisPulse поддерживает два способа разработки:

- **Модульная разработка (рекомендуется):** Создание отдельного пакета модуля, установка через менеджер пакетов, удобно для распространения и управления.
- **Встраиваемая разработка:** Прямое написание обработчиков в проекте, подходит для быстрой разработки прототипов. Подробнее в [быстром старте](quick-start.md).
