# Экологические модули

Сама платформа ErisPulse предоставляет только основные возможности (система событий, система модулей, конфигурация, маршрутизация, логирование и т.д.), **не включая в себя** такие "тяжелые" функции, как GUI, рендеринг изображений, визуализация и т.д. Эти возможности предоставляются **третьими сторонами** и поддерживаются сообществом, и устанавливаются по мере необходимости.

> [!IMPORTANT]
> Документация в этом разделе делится на два типа, способ установки которых различается:
>
> - **Модули** (например, Dashboard / Takumi) устанавливаются с помощью `epsdk install`:
>
>   ```bash
>   epsdk install <имя_модуля>
>   ```
>
> - **Отдельные программы** (например, клиент ErisPulse-App) устанавливаются напрямую из GitHub Releases, без использования `epsdk`.

---

## Рекомендуемые модули

### ErisPulse-Dashboard: панель управления в браузере

Бот висит на сервере, а для запуска/остановки модулей, изменения конфигурации и просмотра логов по-прежнему нужно заходить в терминал? Dashboard переносит всё это в браузер: запуск и остановка модулей, редактирование конфигурации, просмотр логов, мониторинг событий; другие модули также могут регистрировать собственные окна в боковой панели — все страницы управления собраны в одном месте.

```bash
epsdk install Dashboard
```

Документация: [Использование Dashboard и регистрация окон](dashboard.md) ｜ Домашняя страница проекта: [PyPI](https://pypi.org/project/ErisPulse-Dashboard/)

### ErisPulse-Cron: задачи по расписанию

Хотите ежедневно в определённое время отправлять напоминания о чек-ине, запускать периодические задачи по Cron-выражению или опрашивать данные каждые несколько минут? Cron предоставляет три типа задач: однократные / интервальные / по Cron-выражению, с передачей аргументов в колбэки и сохранением в SQLite (задачи не теряются после перезапуска).

```bash
epsdk install Cron
```

Документация: [Задачи по расписанию Cron](cron.md) ｜ Домашняя страница проекта: [GitHub](https://github.com/wsu2059q/ErisPulse-Cron)

### ErisPulse-QvQChat: универсальный агент

Хотите, чтобы в группе был ИИ-ассистент, который действительно работает, а не просто отвечает по ключевым словам? QvQChat — это универсальный агент: цикл инструментов охватывает отправку/получение сообщений / выполнение кода / управление компьютером / генерацию изображений / голос / MCP / суб-агентов, поддерживает потоковый диалог и последовательное воспроизведение инструментов, имеет встроенное окно Dashboard. Также есть три сопутствующих плагина: QvQStalker (подслушивает и вставляет реплики), QvQMemes (мемы), QvQCompanion (очеловеченное общение).

```bash
epsdk install ErisPulse-QvQChat
```

Документация: [Агент QvQChat](qvqchat.md) ｜ Домашняя страница проекта: [GitHub](https://github.com/wsu2059q/ErisPulse-QvQChat)

### ErisPulse-ApiMCP: позвольте ИИ-клиентам управлять ботом

Пользуетесь ИИ-клиентами с поддержкой MCP, такими как Claude Desktop или Claude Code? ApiMCP наоборот открывает рантайм бота в виде 14 инструментов MCP: ИИ может напрямую отправлять и получать сообщения за вас, вызывать установленные модули, просматривать статус платформ, подписываться на события групповых чатов — бот становится «руками и глазами» ИИ.

```bash
epsdk install ErisPulse-ApiMCP
```

Документация: [Руководство по использованию ApiMCP](apimcp.md) ｜ Домашняя страница проекта: [GitHub](https://github.com/wsu2059q/ErisPulse-ApiMCP)

### ErisPulse-Takumi: рендеринг изображений

Для сценариев, где нужно «отправлять картинки» — таблицы лидеров, отчёты о сражениях, карточки расписаний — достаточно написать шаблон, отрендерить его в изображение и отправить в группу: поддерживает HTML / дерево узлов / Jinja / SVG / анимацию (на основе [takumi-py](https://github.com/BalconyJH/takumi-py)), со встроенными китайскими и английскими шрифтами, работает сразу из коробки.

```bash
epsdk install Takumi
```

Документация: [Рендеринг изображений Takumi](takumi.md) ｜ Домашняя страница проекта: [GitHub](https://github.com/ccd2s/ErispulseTakumi) (автор [@ccd2s](https://github.com/ccd2s))

## Официальный клиент (независимое приложение)

### ErisPulse-App: запуск бота прямо на телефоне

Нет постоянного сервера, но вы хотите создавать экземпляры, устанавливать модули и просматривать поток событий в любое время? ErisPulse-App — это официальный клиент для всех платформ (Android / Windows / Linux / macOS): создание / запуск / управление несколькими экземплярами ботов с помощью родного интерфейса, встроенный магазин модулей и конструктор событий, **запуск прямо с телефона**, постоянное присутствие в системном трее на рабочем столе.

Скачайте установочные пакеты для всех платформ с [GitHub Releases](https://github.com/ErisPulse/ErisPulse-App/releases), для этого не требуется `epsdk`.

Документация: [Установка и использование ErisPulse-App](app.md)

## Я тоже хочу добавить свой модуль сюда?

Добро пожаловать, чтобы рекомендовать качественные, повторно используемые модули экосистемы ErisPulse. Требования:

1. Опубликован на [PyPI](https://pypi.org/), и имя пакета начинается с `ErisPulse-`
2. Предоставляет базовый README и примеры использования
3. Активно поддерживается, с ответами на Issue

Авторы модулей, соответствующих вышеуказанным условиям, могут добавить документ `<имя_модуля>.md` в этом каталоге через PR и дополнить соответствующий раздел в рекомендованном списке вверху.
