# Экосистема модулей

Сам фреймворк ErisPulse предоставляет только **ядро** (систему событий, систему модулей, конфигурацию, маршрутизацию, логирование и т.д.) и **не имеет встроенных** функций "тяжелого" типа, таких как GUI, рендеринг изображений, визуализация и т.д. Эти возможности предоставляются **третьими модулями**, поддерживаемыми сообществом, и устанавливаются по мере необходимости.

> [!IMPORTANT]
> Все модули, описанные в документах в этом каталоге, **требуют отдельной установки**, они не входят в состав фреймворка ErisPulse:
>
> ```bash
> epsdk install <имя_модуля>
> ```
>

## Я тоже хочу, чтобы мой модуль был здесь?

Рекомендуем качественные и широко применимые модули экосистемы ErisPulse. Требования:

1. Модуль опубликован на [PyPI](https://pypi.org/) и имя пакета начинается с `ErisPulse-`
2. Предоставляет базовый файл README и примеры использования
3. Активно поддерживается, имеет обратную связь на Issues

Авторы модулей, соответствующих этим условиям, могут внести вклад через Pull Request: создать новый документ `<имя_модуля>.md` в этом каталоге и добавить строку в таблицу «Рекомендуемые модули».
