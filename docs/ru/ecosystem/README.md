# Экосистема

Фреймворк ErisPulse предоставляет только базовые возможности (система событий, модульная система, конфигурация, маршрутизация, логирование и др.), **не вплетая** GUI, рендеринг изображений, визуализацию и другие «тяжелые» функции. Эти возможности предоставляются **сторонними модулями**, поддерживаемыми сообществом, и устанавливаются по мере необходимости.

> [!IMPORTANT]
> Документация в этой категории разделена на два типа в зависимости от способа установки:
>
> - **Модули** (например, Dashboard / Takumi) устанавливаются с помощью `epsdk install`:
>
>   ```bash
>   epsdk install <module_name>
>   ```
>
> - **Независимые приложения** (например, клиент ErisPulse-App) загружаются и устанавливаются напрямую с соответствующих релизов GitHub, без использования `epsdk`.
>

## Хочу добавить свой модуль сюда?

Рекомендуются качественные модули экосистемы ErisPulse, которые могут быть широко переиспользованы. Требования:

1. Выпущен на [PyPI](https://pypi.org/) с именем пакета, начинающимся с `ErisPulse-`
2. Простой README с примерами использования
3. Поддерживается и оперативно реагирует на Issues

Авторы модулей, соответствующих этим условиям, могут через PR создать файл `<ModuleName>.md` в этом каталоге и добавить строку в таблицу «Рекомендуемые модули».

Пожалуйста, верните переведённое содержимое в формате Markdown без лишних слов.
