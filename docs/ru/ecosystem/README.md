# Экологические модули

Сама платформа ErisPulse предоставляет только основные возможности (система событий, система модулей, конфигурация, маршрутизация, логирование и т.д.), **не включая в себя** такие "тяжелые" функции, как GUI, рендеринг изображений, визуализация и т.д. Эти возможности предоставляются **третьими сторонами** и поддерживаются сообществом, и устанавливаются по мере необходимости.

> [!IMPORTANT]
> Документация в этом разделе делится на два типа, способ установки которых различается:
>
> - **Модули** (например, Dashboard / Takumi) устанавливаются с помощью `epsdk install`:
>
>   ```bash
>   epsdk install <имя_модуля>
>   ```
>
> - **Отдельные программы** (например, клиент ErisPulse-App) устанавливаются напрямую из GitHub Releases, без использования `epsdk`.

---

## Рекомендуемые модули

### ErisPulse-Dashboard: Панель управления в браузере

Запускаете бота на сервере, но управляете модулями, настройками и логами через терминал? Dashboard переносит эти функции в браузер: управление модулями, редактирование конфигураций, просмотр логов, мониторинг событий; другие модули могут регистрировать собственные окна в боковой панели, и все управление сосредоточено в одном месте.

```bash
epsdk install Dashboard
```

Документация: [Использование Dashboard и регистрация окон](dashboard.md) ｜ Главная страница проекта: [PyPI](https://pypi.org/project/ErisPulse-Dashboard/)

### ErisPulse-Cron: Планировщик задач

Нужно ежедневно отправлять напоминания о регистрации, выполнять задачи по расписанию с помощью Cron-выражений, или периодически запрашивать данные каждые несколько минут? Cron предоставляет три типа задач: одноразовые, интервальные и по Cron-выражениям, с передачей параметров в обратный вызов, а также SQLite-хранилище (задачи не теряются при перезапуске).

```bash
epsdk install Cron
```

Документация: [Планировщик задач Cron](cron.md) ｜ Главная страница проекта: [GitHub](https://github.com/wsu2059q/ErisPulse-Cron)

### ErisPulse-QvQChat: Общий агент

Хотите, чтобы в группе был AI-ассистент, который может выполнять полезные задачи, а не просто отвечать по ключевым словам? QvQChat — это универсальный агент: циклически обрабатывает отправку и получение сообщений, выполнение кода, управление компьютером, генерацию изображений, голосовые сообщения, MCP и подагентов, поддерживает потоковой диалог и последовательное выполнение инструментов, включает в себя окно Dashboard.

```bash
epsdk install ErisPulse-QvQChat
```

Документация: [Агент QvQChat](qvqchat.md) ｜ Главная страница проекта: [GitHub](https://github.com/wsu2059q/ErisPulse-QvQChat)

### ErisPulse-Takumi: Генерация изображений

Для сцен, где требуется "отправлять изображения", например, рейтинги, отчеты о боях или карточки расписания, достаточно написать шаблон и отрендерить изображение для отправки в группу: поддержка HTML / деревьев узлов / Jinja / SVG / анимации (на основе [takumi-py](https://github.com/BalconyJH/takumi-py)), включает шрифты на китайском и английском языках, готов к использованию без дополнительной настройки.

```bash
epsdk install Takumi
```

Документация: [Генерация изображений Takumi](takumi.md) ｜ Главная страница проекта: [GitHub](https://github.com/ccd2s/ErispulseTakumi) (автор [@ccd2s](https://github.com/ccd2s))

## Официальный клиент (независимое приложение)

### ErisPulse-App: запуск бота прямо на телефоне

Нет постоянного сервера, но вы хотите создавать экземпляры, устанавливать модули и просматривать поток событий в любое время? ErisPulse-App — это официальный клиент для всех платформ (Android / Windows / Linux / macOS): создание / запуск / управление несколькими экземплярами ботов с помощью родного интерфейса, встроенный магазин модулей и конструктор событий, **запуск прямо с телефона**, постоянное присутствие в системном трее на рабочем столе.

Скачайте установочные пакеты для всех платформ с [GitHub Releases](https://github.com/ErisPulse/ErisPulse-App/releases), для этого не требуется `epsdk`.

Документация: [Установка и использование ErisPulse-App](app.md)

## Я тоже хочу добавить свой модуль сюда?

Добро пожаловать, чтобы рекомендовать качественные, повторно используемые модули экосистемы ErisPulse. Требования:

1. Опубликован на [PyPI](https://pypi.org/), и имя пакета начинается с `ErisPulse-`
2. Предоставляет базовый README и примеры использования
3. Активно поддерживается, с ответами на Issue

Авторы модулей, соответствующих вышеуказанным условиям, могут добавить документ `<имя_модуля>.md` в этом каталоге через PR и дополнить соответствующий раздел в рекомендованном списке вверху.
