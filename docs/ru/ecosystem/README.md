# Экосистемные модули

Сама платформа ErisPulse предоставляет только основные возможности (систему событий, систему модулей, конфигурацию, маршрутизацию, логирование и т.д.), **не включая** в себя функции "тяжелого" класса, такие как GUI, рендеринг изображений, визуализация и т.д. Эти возможности предоставляются **пользовательскими модулями**, поддерживаемыми сообществом, которые можно устанавливать по мере необходимости.

> [!IMPORTANT]
> Документация в этом разделе разделена на два типа, с разными способами установки:
>
> - **Модули** (например, Dashboard / Takumi) устанавливаются с помощью `epsdk install`:
>
>   ```bash
>   epsdk install <имя модуля>
>   ```
>
> - **Независимые приложения** (например, клиент ErisPulse-App) устанавливаются напрямую из GitHub Releases, без использования `epsdk`.
>
> - **Веб-сервисы** (например, рабочая среда ErisPulse) не требуют установки, достаточно открыть веб-страницу и войти в систему.

## Рекомендуемые модули

### ErisPulse-Dashboard: панель управления в браузере

Бот работает на сервере, а для запуска и остановки модулей, изменения конфигурации и просмотра логов приходится заходить в терминал? Dashboard переносит всё это в браузер: запуск и остановка модулей, редактирование конфигурации, просмотр логов, мониторинг событий; другие модули также могут регистрировать пользовательские окна в боковой панели — все страницы управления собраны в одном месте.

```bash
epsdk install Dashboard
```

Документация: [Использование Dashboard и регистрация окон](dashboard.md) | Домашняя страница проекта: [PyPI](https://pypi.org/project/ErisPulse-Dashboard/)

### ErisPulse-Cron: задачи по расписанию

Нужно ежедневно отправлять напоминания о чек-ине, запускать периодические задачи по Cron-выражениям или опрашивать данные каждые несколько минут? Cron предоставляет три типа задач: разовые / интервальные / по Cron-выражению, с передачей параметров в колбэки и сохранением в SQLite (задачи не теряются после перезапуска).

```bash
epsdk install Cron
```

Документация: [Задачи по расписанию Cron](cron.md) | Домашняя страница проекта: [GitHub](https://github.com/wsu2059q/ErisPulse-Cron)

### ErisPulse-QvQChat: универсальный агент

Хотите, чтобы в чате был AI-ассистент, который реально выполняет работу, а не просто отвечает по ключевым словам? QvQChat — это универсальный агент: цикл инструментов охватывает приём и отправку сообщений / выполнение кода / управление компьютером / генерацию изображений / голос / MCP / субагентов, поддерживает потоковый диалог и последовательное воспроизведение инструментов, включает встроенное окно Dashboard. Также есть три сопутствующих плагина: QvQStalker (подслушивает и вставляет реплики), QvQMemes (мемы и стикеры), QvQCompanion (человечное сопровождение).

```bash
epsdk install ErisPulse-QvQChat
```

Документация: [Агент QvQChat](qvqchat.md) | Домашняя страница проекта: [GitHub](https://github.com/wsu2059q/ErisPulse-QvQChat)

### ErisPulse-ApiMCP: управление ботом из AI-клиентов

Пользуетесь AI-клиентами с поддержкой MCP, такими как Claude Desktop или Claude Code? ApiMCP, в свою очередь, открывает среду выполнения бота в виде 17 MCP-инструментов: AI может напрямую от вашего имени отправлять и получать сообщения, вызывать установленные модули, просматривать статус платформ и подписываться на события групповых чатов — бот становится «руками и глазами» AI.

```bash
epsdk install ErisPulse-ApiMCP
```

Документация: [Руководство по ApiMCP](apimcp.md) | Домашняя страница проекта: [GitHub](https://github.com/wsu2059q/ErisPulse-ApiMCP)

### ErisPulse-Takumi: рендеринг изображений

Для сценариев, где нужно «отправлять картинки», — таблицы лидеров, отчёты о сражениях, карточки расписания — достаточно написать шаблон, отрендерить его в изображение и отправить в чат: поддерживаются HTML / дерево узлов / Jinja / SVG / анимация (на основе [takumi-py](https://github.com/BalconyJH/takumi-py)), встроены шрифты для китайского и английского языков, всё работает из коробки.

```bash
epsdk install Takumi
```

Документация: [Рендеринг изображений Takumi](takumi.md) | Домашняя страница проекта: [GitHub](https://github.com/ccd2s/ErispulseTakumi) (автор [@ccd2s](https://github.com/ccd2s))

## Официальный клиент (независимое приложение)

### ErisPulse-App: запуск бота прямо на телефоне

Нет постоянного сервера, но хотите создавать экземпляры, устанавливать модули и просматривать поток событий в любое время? ErisPulse-App — это официальный клиент для всех платформ (Android / Windows / Linux / macOS): создавайте, запускайте и управляйте несколькими экземплярами ботов с помощью родного интерфейса, встроенным магазином модулей и конструктором событий, **запуск прямо с телефона**, панель уведомлений на рабочем столе.

Установочные пакеты для всех платформ можно загрузить с [GitHub Releases](https://github.com/ErisPulse/ErisPulse-App/releases), без необходимости использовать `epsdk`.

Документация: [Установка и использование ErisPulse-App](app.md)

## Официальные онлайн-сервисы

### Рабочая станция ErisPulse: магазин модулей и доменное имя для хостинга

Хотите добавить модуль в магазин, присвоить модулю веб-адрес вида `plugin-xxx.erisdev.com` или автоматизировать отправку модуля с помощью скрипта? Рабочая станция — это единый центр учетных записей экосистемы: с помощью одной учетной записи вы можете управлять включением и сертификацией модулей, запрашивать доменные имена для хостинга, генерировать токены доступа и поддерживать функцию «Вход с помощью учетной записи ErisPulse» на вашем сайте. Это онлайн-сервис, **не требующий установки**.

Сайт: [https://workbench.erisdev.com/](https://workbench.erisdev.com/)

Документация: [Руководство по использованию рабочей станции ErisPulse](workbench.md)

## Я тоже хочу добавить свой модуль сюда?

Добро пожаловать, чтобы рекомендовать качественные, повторно используемые модули экосистемы ErisPulse. Требования:

1. Опубликован на [PyPI](https://pypi.org/), и имя пакета начинается с `ErisPulse-`
2. Предоставляет базовый README и примеры использования
3. Активно поддерживается, с ответами на Issue

Авторы модулей, соответствующих вышеуказанным условиям, могут добавить документ `<имя_модуля>.md` в этом каталоге через PR и дополнить соответствующий раздел в рекомендованном списке вверху.
