# ErisPulse-ApiMCP 控制机器人的人工智能客户端

> [!TIP]
> **何时需要阅读本文**：当你希望使用支持 MCP 的人工智能客户端（如 Claude Desktop）直接控制你的机器人——发送和接收消息、调用模块、管理适配器、监控事件流——时阅读本文。否则可以跳过。

[ErisPulse-ApiMCP](https://github.com/wsu2059q/ErisPulse-ApiMCP) 通过 **MCP（Model Context Protocol）** 将机器人运行时的能力开放给人工智能客户端：安装后，Claude Desktop 中将新增 17 个工具，人工智能可以代替你接收和发送消息、排查模块问题、订阅群聊事件、检索框架文档——机器人从“你管理的程序”转变为“人工智能的手和眼”。

> [!IMPORTANT]
> ApiMCP 需要单独安装，并且**必须显式配置 token** 后桥接功能才会启用：
>
> ```bash
> epsdk install ErisPulse-ApiMCP
> ```
>
> 在 `config.toml` 的 `[ApiMCP]` 节中设置 `token = "长随机串"`（或环境变量 `ERISPULSE_APIMCP_TOKEN`）。未配置时，除探活外的所有端点将返回 503，以避免令牌静默泄露。

## Принцип работы

Двухуровневая структура, без каких-либо зависимостей от ИИ в самом роботе:

- **Внутри процесса робота**: модуль ApiMCP подключает REST-мост (`/apimcp/*`, с аутентификацией по токену, по умолчанию ограничение 30 запросов/минуту) к встроенного HTTP-сервера фреймворка.
- **В отдельном процессе**: команда `erispulse-apimcp` запускает stdio-сервер с помощью официального `mcp` SDK и перенаправляет вызовы инструментов MCP на REST-мост робота.

```
Claude Desktop ──MCP(stdio)──► erispulse-apimcp ──HTTP──► REST-мост в процессе робота ──► sdk.*
```

Если робот не работает или мост не настроен, инструмент возвращает понятную ошибку и указания по устранению неполадок, не выбрасывая стек вызовов.

## Подключение Claude Desktop

Отредактируйте файл `claude_desktop_config.json` (Windows: `%APPDATA%\Claude\`; macOS: `~/Library/Application Support/Claude/`):

```json
{
  "mcpServers": {
    "erispulse": {
      "command": "erispulse-apimcp",
      "env": {
        "ERISPULSE_APIMCP_URL": "http://127.0.0.1:8000",
        "ERISPULSE_APIMCP_TOKEN": "ваш токен"
      }
    }
  }
}
```

После сохранения файла перезапустите Claude Desktop полностью. Если в списке инструментов появится сервер `erispulse`, значит подключение успешно. Любой клиент, поддерживающий MCP stdio server (Claude Code, Cursor и т. д.), может подключиться таким же образом.

## Обзор 17 инструментов

| Категория | Инструмент | Описание |
|---|---|---|
| Модуль | `list_modules` / `get_module_info` / `call_module` / `reload_module` | Просмотр и вызов публичных сервисов установленных модулей, запуск горячей перезагрузки |
| Адаптер | `list_adapters` / `get_adapter_status` / `reload_adapter` | Статус онлайн платформы; перезагрузка адаптера по умолчанию отключена |
| Сообщение | `send_message` / `recent_messages` | Отправка текста/изображения/аудио/видео/файла на любую платформу; при развертывании нескольких ботов можно указать отправляющий аккаунт через `account`; просмотр недавних сообщений через [transcript](../advanced/transcript.md) |
| Событие | `subscribe_events` / `unsubscribe` / `poll_events` | Подписка на события сообщений/уведомлений и т.д., кольцевой буфер (по умолчанию 1000 сообщений), инкрементальный опрос |
| Документация | `search_erispulse_docs` / `read_erispulse_doc` / `refresh_erispulse_docs` | Поиск и чтение документации фреймворка ErisPulse; независимый движок документации, загрузка и кэширование по версии фреймворка, не зависит от других модулей |
| Рантайм | `get_topology` / `sdk_health` | Топология рантайма (деконфиденциализированная) и сводка здоровья |

Типичное использование: ИИ сначала вызывает `subscribe_events(["message"])`, затем периодически `poll_events` для наблюдения за разговорами в группе и принимает решение, нужно ли вставить сообщение через `send_message` или вызвать возможность модуля через `call_module`. Если ИИ не уверен, как использовать определённую функциональность фреймворка, он может сначала выполнить `search_erispulse_docs`, чтобы найти документацию, а затем приступить к работе.

## Ключевые моменты безопасности

- **Токен — это полный контроль**: токен позволяет читать сообщения, отправлять сообщения и вызывать методы модулей из белого списка. Никогда не добавляйте токен в репозиторий или не публикуйте в общедоступных каналах; в сценариях с несколькими арендаторами создавайте несколько экземпляров бота.
- **Минимальные права доступа**: `module_call_whitelist` ограничивает список вызываемых модулей (поддерживается точный доступ по формату `модуль.метод`), `send_target_whitelist` ограничивает целевые адреса отправки (например, только определённая группа), `allow_adapter_reload` оставьте по умолчанию отключённым.
- **Только для локального использования**: при использовании только на локальной машине установите фреймворк HTTP-сервера как `server.host = "127.0.0.1"`; при использовании на нескольких машинах необходимо использовать внутреннюю сеть + обратный прокси + TLS.
- Вывод данных проходит очистку по ключам (ключи, относящиеся к ключам/пути, полностью удаляются); глубокая очистка — это обязанность самого модуля, не открывайте подписки на чувствительные сессии.

Полный список конфигурационных параметров (емкость буфера, окно восстановления, белый список типов событий и т.д.) и подробности REST-эндпоинтов см. в [README проекта](https://github.com/wsu2059q/ErisPulse-ApiMCP).
