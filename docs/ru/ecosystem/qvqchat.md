# ErisPulse-QvQChat — универсальный агент

> [!TIP]
> **Когда стоит читать этот документ**: когда вы хотите добавить боту возможности ИИ-агента (цикл инструментов, потоковый диалог, MCP, долговременная память) или открыть службы своего модуля для вызова агентом. Если это не нужно — пропустите.

[ErisPulse-QvQChat](https://pypi.org/project/ErisPulse-QvQChat/) — это **модуль универсального агента**, построенный вокруг цикла инструментов: приём и отправка сообщений, вызов служб модулей экосистемы, написание и выполнение кода, управление компьютером, генерация изображений и речи, управление задачами по расписанию и долговременной памятью — всё выполняется через единый протокол инструментов.

> [!IMPORTANT]
> QvQChat требует отдельной установки:
>
> ```bash
> epsdk install ErisPulse-QvQChat
> ```
>
> Также необходимо добавить в «Пул моделей» хотя бы одну совместимую с OpenAI модель (Base URL, API Key, имя модели).

## Основные возможности

| Возможность | Описание |
|---|---|
| Цикл инструментов | Модель выдаёт вызовы инструментов → параллельное выполнение → подстановка результатов → продолжение рассуждений, пока не будет дан финальный ответ |
| Потоковый диалог | Посимвольный вывод через SSE, шаги инструментов видны в реальном времени; после обновления страницы или ухода и возвращения прогресс не теряется |
| Сжатие контекста | При превышении порога token старый диалог автоматически сжимается в резюме (по умолчанию оценка 128000, настраивается) |
| Мост служб экосистемы | Автоматическое обнаружение служб, объявленных модулями, и их преобразование в инструменты; установка или удаление модулей добавляет и убирает возможности |
| MCP-клиент | stdio и Streamable HTTP, инструменты MCP объединяются в единый набор инструментов |
| Подагенты | `spawn_agent` направляет подагента с независимой сессией на исследование задачи, возвращаются только итоговые выводы |
| Выполнение внутри процесса | `run_python_sdk` запускает Python в основном процессе с прямым доступом к объектам среды выполнения |
| Управление компьютером | Трёхуровневая безопасная песочница (strict / standard / permissive), подтверждение опасных операций, полный аудит |
| Визуальное понимание | Изображения автоматически передаются модели (при отсутствии поддержки автоматически удаляются с повторной попыткой) |
| Вложения | Любые файлы сохраняются на диск с дедупликацией по hash, путь передаётся ИИ для самостоятельной обработки; вставка скриншотов через Ctrl+V |
| Общий доступ к сессиям | Временные ссылки только для чтения (срок действия + лимит token), экспорт в Markdown |
| Задачи по расписанию | cron / однократные / с интервалом, с сохранением состояния, права наследуются от создателя |
| Захват сессии | Администратор может передать агенту сессию в монопольное управление |
| Система персон | Системный промпт + вступительный диалог + белый список инструментов, возможна привязка к сессиям |
| Долговременная память | Записи памяти для каждой сессии, извлекаются по схожести и внедряются в контекст |
| Автоименование ИИ | После первого ответа в сессии автоматически генерируется краткий заголовок |

## Расширение через модули

Любой модуль ErisPulse, объявляющий `services`, автоматически становится инструментом QvQChat — специальный интерфейс не требуется:

```python
from ErisPulse.Core.Bases import BaseModule, ModuleMeta

class Main(BaseModule):
    @staticmethod
    def get_meta() -> ModuleMeta:
        return ModuleMeta(name="Draw", services=[
            {"name": "draw", "description": "Генерирует изображение по описанию, возвращает URL изображения"},
        ])

    async def draw(self, prompt: str, size: str = "1024x1024"):
        return {"image_url": "https://..."}
```

Сигнатуры методов служб автоматически отображаются в определения параметров JSON Schema инструмента, первая строка docstring используется как описание параметра.

### Глубокая интеграция (опционально)

Модуль может дополнительно реализовать любые из следующих служб, каждая из которых **независима и опциональна** — модуль может заниматься только расширением персон или только внедрением промптов:

#### `qvq_prompts()` → внедрение системных промптов

Возвращает `list[str]` или `list[{"text": str, "priority": int}]`, элементы объединяются в порядке возрастания `priority`.

```python
async def qvq_prompts(self):
    return [
        {"text": "После создания изображения отправьте его пользователю через send_message.", "priority": 10},
        {"text": "Поддерживаемые стили: аниме, реализм, акварель, пиксель-арт.", "priority": 20},
    ]
```

#### `qvq_personas()` → регистрация предустановок персон

Возвращает список персон, к id автоматически добавляется префикс `ext.<имя модуля>.`, при удалении модуля выполняется автоматическая очистка. Подходит для модулей, специализирующихся на расширении персон (эмоциональный компаньон, переводчик, рецензент кода и т.д.).

```python
async def qvq_personas(self):
    return [
        {"id": "companion", "name": "Тёплый собеседник", "system": "Ты — тёплый и заботливый собеседник..."},
        {"id": "coder", "name": "Наставник по коду", "system": "...", "tools": ["read_file", "run_python"]},
    ]
```

`tools` опционально ограничивает подмножество инструментов, доступных данной персоне.

#### `qvq_schemas()` → явные схемы параметров

Возвращает `dict[имя службы, JSON Schema]`, переопределяя вывод из сигнатуры метода. Используется, когда параметры сложны или требуется строгая валидация.

```python
async def qvq_schemas(self):
    return {
        "draw": {
            "type": "object",
            "properties": {
                "prompt": {"type": "string", "description": "Описание изображения"},
                "size": {"type": "string", "enum": ["512x512", "1024x1024"]},
            },
            "required": ["prompt"],
        },
    }
```

### Моменты обновления

Моменты обновления служб глубокой интеграции: запуск, установка и удаление модулей, ручное обновление на странице «Инструменты» в Dashboard.

## Подписка на события

QvQChat рассылает два события жизненного цикла:

| Событие | Момент | Полезная нагрузка |
|---|---|---|
| `qvq.message` | Получено сообщение пользователя | `chat_key` `platform` `sender_id` `sender_name` `text` `is_group` |
| `qvq.replied` | После отправки ответа | `chat_key` `reply` `tools` |

```python
async def setup(self):
    sdk.lifecycle.on("qvq.message", self.on_message)
```

## Вызов в качестве службы

| Служба | Сигнатура | Описание |
|---|---|---|
| `chat` | `(session_id, prompt, persona="")` | Диалог с агентом, возвращает текст |
| `run_prompt` | `(chat_key, prompt, ...)` | Запускает промпт, результат может быть отправлен в целевую сессию |
| `get_status` | `()` | Сводка состояния выполнения |

## Сопутствующие плагины

Три независимых модуля расширяют QvQChat и заодно демонстрируют, на что способны точки расширения — после установки QvQChat добавляйте их по мере необходимости:

| Плагин | Что делает |
|---|---|
| [ErisPulse-QvQStalker](https://github.com/wsu2059q/ErisPulse-QvQStalker) | Подслушивает групповые чаты и автоматически вмешивается в разговор: отслеживание активности, пятиуровневая оценка и уровень импульсивности совместно определяют, когда агенту вступить; 15 параметров поведения настраиваются прямо на странице настроек |
| [ErisPulse-QvQMemes](https://github.com/wsu2059q/ErisPulse-QvQMemes) | Прививает агенту привычку к мемам и стикерам: инструмент `send_sticker` позволяет модели самой выбирать, какой стикер отправить, изображения из групповых чатов автоматически собираются и размечаются визуальной моделью |
| [ErisPulse-QvQCompanion](https://github.com/wsu2059q/ErisPulse-QvQCompanion) | Антропоморфное сопровождение: внедрение персоны и тона общения, инициативные реплики по уровню импульсивности, периоды тишины и дневной лимит |

Все три плагина подключаются через соглашения о службах, описанные выше в разделе «Расширение через модули», и сами являются эталонной реализацией написания расширений.

## Следующие шаги

- **Превратите свой модуль в инструмент агента**: достаточно объявить `services` в `get_meta()`, семантика полей описана в [API основных модулей — контракт служб](../api-reference/core-modules.md)
- **Подпишитесь на сообщения агента для интеграции**: слушайте `qvq.message` / `qvq.replied` с помощью [событий жизненного цикла](../advanced/lifecycle.md)
- **Не нужен агент, а нужна лишь многошаговая форма вопросов и ответов**: встроенный [Conversation — многошаговый диалог](../advanced/conversation.md) — более лёгкое решение
- **Управление через веб-интерфейс**: используйте вместе с боковой панелью [ErisPulse-Dashboard](dashboard.md)
