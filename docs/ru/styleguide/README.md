# Стиль руководства

Данный каталог содержит инженерные дисциплины и руководства по написанию кода для проекта ErisPulse.

## Список документов

- [Словарь терминов (единственный источник истины)](glossary.md) - Определения терминов, подверженных изменению, таких как Client/HttpClient, storage/env/StorageManager, BaseConfig/AdapterConfig, scope, трехмерность, принадлежность, контракт сервиса/каталог/белый список и т.д.
- [Стиль комментариев](docstring.md) - Форматирование комментариев к методам и строкам документации, а также соглашения по тегам
- [Правила надежности инженерии](engineering.md) - Классификация трассировки исключений, классификация журналов, централизация параметров поведения, контракт API, запрет на использование синглтонов, дисциплина очистки и отката, дисциплина тестирования
- [Правила документации и внешнего письма](docs-writing.md) - Стиль написания документации, маркировка версий, трехчастная структура README и страницы выпуска, сценарное выражение, написание записей изменений

## Целевая аудитория

- Основные участники ErisPulse
- Разработчики модулей и адаптеров
- Участники, отвечающие за поддержку README и внешних страниц
- Разработчики, которым необходимо генерировать API-документацию

## Отношения с другими стандартами

- [Технические стандарты](../standards/) - **Технические** спецификации адаптера (типы сессий, преобразование событий, форма API); данный раздел представляет собой **инженерную и письменную** дисциплину, оба дополняют друг друга и не пересекаются
- `CONTRIBUTING.md` - Процесс внесения вклада и CI-ограничения (механически проверяемые части правил из данного раздела выполняются сценариями CI)
- `CHANGELOG.md` в начале «Правила написания» - Подробные спецификации записей изменений (в настоящем документе приводится только ссылка, без дублирования основного текста)
