# Стиль руководства

Данный каталог содержит стилистические и документационные нормы проекта ErisPulse.

## Список документации

- [Стиль документирования](docstring.md) - Стандарты форматирования комментариев и строк документирования методов

## Целевая аудитория

Данные документы предназначены для следующих разработчиков:

- Основных участников ErisPulse
- Разработчиков модулей и адаптеров
- Разработчиков, которым необходимо создавать API-документацию

## Цель

Цель руководства по стилю:

- Обеспечение согласованности комментариев в коде
- Поддержка автоматической генерации документации API
- Повышение читаемости и сопровождаемости кода

## Преимущества соблюдения стандартов

- Единый стиль кода
- Полная документация API
- Лучшая командная работа
- Поддержка автоматической генерации документации
