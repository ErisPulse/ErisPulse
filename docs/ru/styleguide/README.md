# Руководство по стилю

Этот каталог содержит спецификации стиля кода и документации для проекта ErisPulse.

## Документация

- [Стандарты оформления комментариев](docstring.md) - Спецификации формата для комментариев методов и строк документации

## Целевая аудитория

Эти документы подходят для следующих разработчиков:

- Основные разработчики ядра ErisPulse
- Разработчики модулей и адаптеров
- Разработчики, которым необходимо генерировать документацию API

## Цели

Цели руководства по стилю:

- Обеспечение единообразия комментариев в коде
- Поддержка автоматической генерации документации API
- Повышение читаемости и поддерживаемости кода

## Преимущества использования стандарта

- Единый стиль кода
- Комплексная документация API
- Улучшение командной работы
- Поддержка автоматизированной генерации документации
