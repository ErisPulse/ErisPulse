# Руководство по выбору

> [!TIP]
> **Когда стоит прочитать**: если вы выбираете между различными фреймворками для роботов / платформами ИИ-роботов и хотите понять, подходит ли вам ErisPulse, а подходит ли он не всем, прочитайте это. Если вы уже используете ErisPulse, пропустите.

Мы не считаем, что существует "лучший фреймворк", а только "фреймворк, подходящий для сценария". Этот раздел с помощью таблицы объясняет различия в дизайне ErisPulse и распространенных альтернатив, помогая вам принять решение — включая случаи, когда **не стоит** выбирать нас.

## Сценарии быстрой проверки

- **Хотите готовый к использованию AI-чат-бот без написания кода**: Начальное использование AstrBot / LangBot будет быстрее; если вы цените горячую перезагрузку, модульный рынок и поддержку 16 платформ, то с помощью ErisPulse + [QvQChat](../ecosystem/qvqchat.md) + [Dashboard](../ecosystem/dashboard.md) вы также достигнете той же цели, но на инициализацию уйдет примерно на полчаса больше.
- **Нужно писать бизнес-код и переиспользовать его на разных платформах**: Unified Event Model OneBot12 от ErisPulse позволяет естественным образом переносить один обработчик на разные платформы без необходимости писать адаптационные ветки для различий между платформами.
- **Хотите создать экосистему для своих модулей/AI**: Сервис объявления модулей ErisPulse автоматически становится инструментом AI ([QvQChat](../ecosystem/qvqchat.md) автоматически обнаруживает), экосистема и агенты нативно взаимодействуют друг с другом.
- **У вас уже есть множество плагинов NoneBot**: Многолетняя экосистема плагинов NoneBot2 является объективным преимуществом, но необходимо самостоятельно оценить стоимость миграции.
