# API Справочник

Этот раздел содержит справочную документацию по API фреймворка ErisPulse.

## Список документации

| Документ | Описание |
|------|------|
| [API основных модулей](core-modules.md) | Быстрый справочник по API для Storage, Config, Logger, Adapter, Module, Lifecycle, Router, HTTP Client |
| [API системы событий](event-system.md) | Справка по API для модулей событий Command, Message, Notice, Request, Meta |
| [API системы адаптеров](adapter-system.md) | Справка по API для менеджера адаптеров, SendDSL, middleware и управления состоянием бота |
| [Автоматически генерируемое API](auto_api/README.md) | Полная документация API, автоматически генерируемая из docstring в исходном коде |

> Ручная документация API имеет упор на примеры использования и быстрый поиск; автоматически генерируемая документация API содержит полные сигнатуры классов/методов, они дополняют друг друга.

## Обзор модулей

### Основные модули

| Модуль | Путь доступа | Описание |
|------|------|------|
| `sdk.storage` | `sdk.storage` | Хранилище ключ-значение на базе SQLite + цепочечные SQL-запросы |
| `sdk.config` | `sdk.config` | Управление конфигурацией в формате TOML |
| `sdk.logger` | `sdk.logger` | Модульная система логирования, поддерживающая дочерние логгеры |
| `sdk.adapter` | `sdk.adapter` | Управление многоплатформенными адаптерами |
| `sdk.module` | `sdk.module` | Управление регистрацией, загрузкой и выгрузкой модулей |
| `sdk.lifecycle` | `sdk.lifecycle` | Управление событиями жизненного цикла |
| `sdk.router` | `sdk.router` | Управление маршрутизацией HTTP/WebSocket |
| `sdk.client` | `sdk.client` | Унифицированный HTTP/WS клиент |

### Система событий

| Модуль | Импортный путь | Описание |
|------|------|------|
| `command` | `ErisPulse.Core.Event.command` | Обработка команд (парсинг префиксов, псевдонимы) |
| `message` | `ErisPulse.Core.Event.message` | События сообщений (личные, групповые, @упоминания) |
| `notice` | `ErisPulse.Core.Event.notice` | События уведомлений (добавление друзей, изменения в составе группы) |
| `request` | `ErisPulse.Core.Event.request` | События запросов (запросы в друзья, приглашения в группы) |
| `meta` | `ErisPulse.Core.Event.meta` | Метасобытия (подключение, отключение, пульс) |

### Базовые классы

| Базовый класс | Импортный путь | Описание |
|------|------|------|
| `BaseModule` | `ErisPulse.Core.Bases.module.BaseModule` | Базовый класс модуля (on_load/on_unload) |
| `BaseAdapter` | `ErisPulse.Core.Bases.adapter.BaseAdapter` | Базовый класс адаптера (start/shutdown/call_api) |
