# Инструментарий runtime

> [!TIP]
> **Когда нужно читать эту статью**: если вы хотите получить обзор всех
> инструментов, доступных для прямого импорта из пакета `ErisPulse.runtime`.
> Подробное описание использования каждого инструмента находится в соответствующих
> тематических документах, в этой статье представлены краткие справочные сведения
> и описание использования инструментов, не относящихся к конкретной теме.

`ErisPulse.runtime` — это агрегирующий слой экспорта фреймворка: он собирает
разрозненные инструменты времени выполнения из разных модулей в единый входной
точку, и скрипты, модули, адаптеры могут использовать их через `from ErisPulse.runtime import X`,
не запоминая глубокие пути.

## dict_to_dataclass: dict → типобезопасный объект

Обратное направление декларативной конфигурации dataclass — преобразование произвольного dict (ответ API, webhook payload, пользовательский ввод) в типобезопасный экземпляр по объявлению, вместо ручного написания цепочек `data.get("x", default)`:

```python
from dataclasses import dataclass, field
from ErisPulse.runtime import dict_to_dataclass

@dataclass
class WebhookPayload:
    order_id: str
    amount: float = 0.0
    tags: list = field(default_factory=list)
    remark: str = ""

payload = dict_to_dataclass(WebhookPayload, {
    "order_id": "A-1024",
    "amount": "99.5",          # Автоматическое преобразование str → float
    "unknown_key": "игнорируется",      # Необъявленные поля автоматически игнорируются
})
payload.amount                   # 99.5 (float)
```

- Преобразование типов (str → int/float и т.д.), заполнение значений по умолчанию, рекурсивное заполнение вложенных dataclass
- Перекрытие переменными окружения: при наличии метаданных `metadata={"env": "NAME"}` приоритет переменных окружения > данных > значения по умолчанию
- Внутри декларативных конфигурационных классов (`ConfigClass` / `BaseConfig`) для теплого обновления обратный вызов от dict → объекта конфигурации выполняется с помощью этой функции
