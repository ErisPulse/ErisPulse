## Целевая аудитория

Эти документы подходят для следующих разработчиков:

- Разработчиков, которые уже знакомы с базовыми функциями ErisPulse
- Разработчиков, которым необходимо глубоко понять внутренние механизмы фреймворка
- Разработчиков, которым необходимо оптимизировать производительность или реализовать сложные функции
