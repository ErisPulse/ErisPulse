# Расширенные темы

Данный раздел содержит расширенные возможности и углубленные темы фреймворка ErisPulse.

## Список документации

- [Процесс запуска и ручное управление](startup.md) - Разбор цепочки запуска (Finder/Loader/Manager/Router) и ручной полный запуск
- [Ленивая загрузка системы](lazy-loading.md) - Принцип работы системы ленивой загрузки модулей, конфигурация и событийно-активируемая ленивая активация (activate_on)
- [Область видимости (scope)](scope.md) - Трехмерное управление областью видимости: доступность модуля / доступ к событиям / ограничения исходящих действий (включая правила детализации на уровне методов и наследование связей merge)
- [Система принадлежности (owner)](ownership.md) - Принадлежность ресурсов и автоматическая очистка: контекстная система owner, панорама принадлежащих ресурсов, последовательность очистки при выгрузке и границы проектирования
- [Система интерактивных сеансов](interaction.md) - wait_reply / таймер сеанса / многопоточное ожидание / взаимоисключающий сеансный талон / почтовый ящик / транзакции сообщений / трассировка цепочки
- [Коммуникация между модулями](module-communication.md) - RPC-протоколизированный (module.call), сервисные контракты и каталог, направленные события, воспроизведение при холодном запуске, идемпотентная дедупликация событий
- [Международная локализация (i18n)](i18n.md) - Поддержка нескольких языков, регистрация переводов и определение языка
- [Управление жизненным циклом](lifecycle.md) - Использование системы событий жизненного цикла
- [Менеджер маршрутизации](router.md) - Управление HTTP и WebSocket маршрутизацией
- [HTTP клиент](http-client.md) - Единый HTTP-клиент для запросов
- [Подробное руководство MessageBuilder](message-builder.md) - Двухрежимное использование MessageBuilder OneBot12 для построения сообщений
- [SQL-конструктор запросов](sql-builder.md) - Общий SQL-конструктор цепных запросов и абстрактный слой хранилища
- [Хранилище данных](storage-backends.md) - Выбор, настройка и переключение асинхронных нативных хранилищ sqlite / mysql / postgres
- [Система исключений и руководство по отлову](errors.md) - Все типы исключений фреймворка, места их возникновения и рекомендации по отлову
- [Типы сеансов](../standards/session-types.md) - Определение типов сеансов, сопоставление и регистрация пользовательских типов
- [Conversation многоконтекстный диалог](conversation.md) - Интерактивные методы многоконтекстного диалога

> [!NOTE]
> Документация по **модулям экосистемы**, таким как Dashboard и Takumi для рендеринга изображений, была перемещена в каталог [Экосистема модулей](../ecosystem/README.md).

## Целевая аудитория

Данные документы предназначены для следующих разработчиков:

- Разработчики, уже знакомые с основными функциями ErisPulse
- Разработчики, желающие глубже понять внутренние механизмы фреймворка
- Разработчики, которым необходимо оптимизировать производительность или реализовать сложные функции
