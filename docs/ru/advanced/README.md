# Расширенные темы

Данный раздел содержит расширенные возможности и углубленные темы фреймворка ErisPulse.

## Список документов

- [Процесс запуска и ручное управление](startup.md) - Разбор цепочки запуска (Finder/Loader/Manager/Router) и ручной полный запуск
- [Система ленивой загрузки](lazy-loading.md) - Принцип работы системы ленивой загрузки модулей, настройка и событийное активирование (activate_on)
- [Область видимости (scope)](scope.md) - Трехмерное управление областью видимости: доступность модуля / доступ к событиям / ограничение исходящих действий (включая тонкие правила на уровне методов и наследование привязок merge)
- [Система владельцев (owner)](ownership.md) - Принадлежность ресурсов и автоматическая очистка: контекст owner, панорама принадлежащих ресурсов, последовательность очистки при выгрузке и границы проектирования
- [Международная локализация (i18n)](i18n.md) - Поддержка нескольких языков, регистрация переводов и определение языка
- [Управление жизненным циклом](lifecycle.md) - Использование системы событий жизненного цикла
- [Менеджер маршрутизации](router.md) - Управление маршрутизацией HTTP и WebSocket
- [HTTP-клиент](http-client.md) - Единый HTTP-клиент для запросов
- [Подробности MessageBuilder](message-builder.md) - Двухрежимное использование конструктора сообщений OneBot12
- [SQL-конструктор запросов](sql-builder.md) - Общий SQL-конструктор цепных запросов и абстракция хранилища
- [Система типов сессий](../standards/session-types.md) - Определение типов сессий, сопоставление и регистрация пользовательских типов
- [Conversation многократные диалоги](conversation.md) - Взаимодействие контекста многократных диалогов

> [!NOTE]
> Документация по виджетам Dashboard, рендерингу изображений Takumi и другим **модулям экосистемы** была перемещена в каталог [Экосистема модулей](../ecosystem/README.md).

## Для кого предназначено

Данные документы предназначены для следующих разработчиков:

- Разработчиков, уже знакомых с основными функциями ErisPulse
- Разработчиков, желающих глубже понять внутренние механизмы фреймворка
- Разработчиков, стремящихся оптимизировать производительность или реализовать сложные функции
