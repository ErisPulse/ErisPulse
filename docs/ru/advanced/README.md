# Расширенные темы

Данный раздел содержит расширенные возможности и углубленные темы фреймворка ErisPulse.

## Список документации

- [Процесс запуска и ручное управление](startup.md) - Разбор цепочки запуска (Finder/Loader/Manager/Router) и ручной полный запуск
- [Ленивая загрузка системы](lazy-loading.md) - Принцип работы системы ленивой загрузки модулей, конфигурация и активация по событиям (activate_on)
- [Области видимости (scope)](scope.md) - Трехмерное управление областями: доступность модуля / доступ к событиям / ограничение исходящих действий (включая тонкие правила на уровне методов и наследование связей merge)
- [Система принадлежности (owner)](ownership.md) - Принадлежность ресурсов и автоматическая очистка: контекст owner, обзор принадлежащих ресурсов, последовательность очистки при выгрузке и границы проектирования
- [Модули-тени и серая/зеленая поставка](shadow.md) - Независимый параллельный запуск новой версии модуля с отдельным owner: перехват исходящих действий и бухгалтерия, сравнение поведения diff, промоут (promote) и откат при сбое
- [Система интерактивных сессий](interaction.md) - wait_reply / Таймер сессии / Многоканальное ожидание / Исключительный сеансный токен / Ящик получателя / Транзакции сообщений / Отслеживание цепочки
- [Коммуникация между модулями](module-communication.md) - RPC-протокол (module.call), сервисные контракты и каталоги, направленные события, воспроизведение при холодном запуске, идемпотентность и удаление дубликатов событий
- [Международная локализация (i18n)](i18n.md) - Поддержка нескольких языков, регистрация переводов и определение языка
- [Управление жизненным циклом](lifecycle.md) - Использование системы событий жизненного цикла
- [Менеджер маршрутизации](router.md) - Управление HTTP и WebSocket маршрутов
- [HTTP клиент](http-client.md) - Единый HTTP клиент для запросов
- [Подробности MessageBuilder](message-builder.md) - Двухрежимное использование MessageBuilder для OneBot12
- [SQL-конструктор запросов](sql-builder.md) - Общий SQL-конструктор цепочечных запросов и абстракция хранилищ
- [Хранилища](storage-backends.md) - Выбор, конфигурация и переключение асинхронных хранилищ sqlite / mysql / postgres
- [Система исключений и руководство по обработке](errors.md) - Все типы исключений фреймворка, места возникновения и рекомендации по перехвату
- [Типы сессий](../standards/session-types.md) - Определение типов сессий, сопоставление и регистрация пользовательских типов
- [Conversation многократные диалоги](conversation.md) - Взаимодействие в контексте многократных диалогов

> [!NOTE]
> Документация для **модулей экосистемы**, таких как Dashboard и Takumi, теперь находится в каталоге [Экосистема модулей](../ecosystem/README.md).

## Целевая аудитория

Данные документы предназначены для следующих разработчиков:

- Разработчики, уже знакомые с основными функциями ErisPulse
- Разработчики, желающие глубже понять внутренние механизмы фреймворка
- Разработчики, которым необходимо оптимизировать производительность или реализовать сложные функции
