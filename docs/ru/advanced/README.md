# Продвинутые темы

Этот раздел содержит расширенные возможности и глубокие темы фреймворка ErisPulse.

## Список документации

- [Процесс запуска и ручное управление](startup.md) — разбор цепочки запуска (Finder/Loader/Manager/Router) и ручный полный запуск
- [Система отложенной загрузки](lazy-loading.md) — принципы работы и конфигурация системы модулей отложенной загрузки
- [Интернационализация (i18n)](i18n.md) — поддержка нескольких языков, регистрация переводов и определение языка
- [Управление жизненным циклом](lifecycle.md) — использование системы событий жизненного цикла
- [Менеджер маршрутизации](router.md) — управление HTTP и WebSocket маршрутизацией
- [HTTP клиент](http-client.md) — унифицированный клиент HTTP запросов
- [Подробное описание MessageBuilder](message-builder.md) — двухрежимное использование построителя сегментов сообщений OneBot12
- [SQL построитель запросов](sql-builder.md) — универсальный цепочечный построитель SQL запросов и абстракция бэкенда хранения
- [Система типов сессий](session-types.md) — определение, сопоставление и регистрация пользовательских типов сессий
- [Многоразовая беседа Conversation](conversation.md) — методы взаимодействия с контекстом многоразовых бесед

> [!NOTE]
> Документация для модулей сторонней экосистемы, таких как регистрация виджетов Dashboard, рендеринг изображений Takumi, была перенесена в директорию [экосистема модулей](../ecosystem/README.md).

## Для кого подходит

Эта документация подходит для следующих разработчиков:

- Разработчиков, уже знакомых с базовыми возможностями ErisPulse
- Разработчиков, желающих глубоко понять внутренние механизмы фреймворка
- Разработчиков, которым необходимо оптимизировать производительность или реализовать сложные функции
