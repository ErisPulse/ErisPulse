# Расширенные темы

Данный раздел содержит расширенные возможности и углубленные темы фреймворка ErisPulse.

## Список документации

- [Процесс запуска и ручное управление](startup.md) - Разбор цепочки запуска (Finder/Loader/Manager/Router) и ручной полный запуск
- [Ленивая загрузка системы](lazy-loading.md) - Принцип работы системы ленивой загрузки модулей, конфигурация и событийное управление активацией (activate_on)
- [Область видимости (scope)](scope.md) - Трехмерное управление областью видимости: доступность модуля / доступ к событиям / ограничение исходящих действий (включая тонкие правила на уровне методов и наследование привязок merge)
- [Система принадлежности (owner)](ownership.md) - Принадлежность ресурсов и автоматическая очистка: контекст owner, карта принадлежности ресурсов, последовательность очистки при выгрузке и границы проектирования
- [Система интерактивных сессий](interaction.md) - wait_reply / таймер сессии / многоканальное ожидание / взаимоисключающие сессии / почтовый ящик / транзакции сообщений / трассировка цепочки
- [Межмодульная коммуникация](module-communication.md) - RPC-протокол (module.call), сервисные контракты и каталоги, направленные события, воспроизведение при холодном запуске, идемпотентная дедупликация событий
- [Международная локализация (i18n)](i18n.md) - Поддержка нескольких языков, регистрация переводов и обнаружение языка
- [Управление жизненным циклом](lifecycle.md) - Методы использования системы событий жизненного цикла
- [Менеджер маршрутизации](router.md) - Управление HTTP и WebSocket маршрутизацией
- [HTTP-клиент](http-client.md) - Единый HTTP-клиент для запросов
- [Подробное руководство MessageBuilder](message-builder.md) - Двухрежимное использование MessageBuilder OneBot12 для построения сообщений
- [SQL-построитель запросов](sql-builder.md) - Общий SQL-построитель запросов с цепочечной синтаксической конструкцией и абстрактный слой хранения
- [Хранилище данных](storage-backends.md) - Выбор, конфигурация и переключение асинхронных хранилищ sqlite / mysql / postgres
- [Система типов сессий](../standards/session-types.md) - Определение типов сессий, сопоставление и регистрация пользовательских типов
- [Conversation многоконтактный диалог](conversation.md) - Методы взаимодействия контекста многоконтактного диалога

> [!NOTE]
> Документация по модулям сторонней экосистемы, таким как Dashboard и Takumi, была перемещена в каталог [Экосистемные модули](../ecosystem/README.md).

## Целевая аудитория

Данные документы предназначены для следующих разработчиков:

- Разработчики, уже знакомые с основными функциями ErisPulse
- Разработчики, желающие глубже понять внутренние механизмы фреймворка
- Разработчики, которым необходимо оптимизировать производительность или реализовать сложные функции
