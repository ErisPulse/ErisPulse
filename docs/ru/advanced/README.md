# Расширенные темы

Данный раздел содержит расширенные возможности и углубленные темы фреймворка ErisPulse.

## Список документации

- [Процесс запуска и ручное управление](startup.md) - Разбор цепочки запуска (Finder/Loader/Manager/Router) и ручной полный запуск
- [Ленивая загрузка системы](lazy-loading.md) - Принцип работы системы ленивой загрузки модулей, конфигурация и событийное управление ленивым активированием (activate_on)
- [Область видимости (scope)](scope.md) - Трехмерное управление областью видимости: доступность модуля / доступ к событиям / ограничение исходящих действий (включая тонкие правила на уровне методов и наследование связей merge)
- [Система принадлежности (owner)](ownership.md) - Принадлежность и автоматическая очистка ресурсов: контекст owner, общий обзор принадлежащих ресурсов, последовательность очистки при выгрузке и границы проектирования
- [Теневые модули и серая трансформация](shadow.md) - Независимый параллельный запуск новых версий модулей с отдельным owner: учет исходящих действий, сравнение поведения diff, превращение в основной модуль promote и откат при сбое
- [Система интерактивных сессий](interaction.md) - wait_reply / таймер сессии / многоканальное ожидание / взаимоисключающие сессионные аренды / почтовый ящик / транзакции сообщений / трассировка цепочки
- [Взаимодействие между модулями](module-communication.md) - RPC-протоколизированный (module.call), сервисные контракты и каталог, направленные события, воспроизведение при холодном запуске, идемпотентность и удаление дубликатов событий
- [Международная локализация (i18n)](i18n.md) - Поддержка нескольких языков, регистрация переводов и определение языка
- [Управление жизненным циклом](lifecycle.md) - Использование системы событий жизненного цикла
- [Менеджер маршрутизации](router.md) - Управление HTTP и WebSocket маршрутизацией (включая регистрацию с одним параметром, соглашение о ответах в виде кортежей)
- [Пул подключений и трансляции](connections.md) - Регистратор подключений: трансляция, подписка на группы, передача и повторное использование между модулями, просмотр пула подключений
- [HTTP клиент](http-client.md) - Единый HTTP-клиент для запросов
- [Почтовый ящик сессии](transcript.md) - Автоматическая запись сообщений: переключатель политик хранения, API перезаписи в режиме выполнения и риски/аудит
- [Подробное руководство MessageBuilder](message-builder.md) - Двухрежимное использование MessageBuilder OneBot12 для построения сообщений
- [SQL-конструктор запросов](sql-builder.md) - Общий SQL-конструктор цепочечных запросов и абстракция хранилища
- [Хранилище](storage-backends.md) - Выбор, конфигурация и переключение асинхронных хранилищ sqlite / mysql / postgres
- [Система исключений и руководство по перехвату](errors.md) - Все типы исключений в фреймворке, места возникновения и рекомендации по перехвату
- [Система типов сессий](../standards/session-types.md) - Определение типов сессий, сопоставление и регистрация пользовательских типов
- [Conversation многократные диалоги](conversation.md) - Методы взаимодействия контекста многократных диалогов

> [!NOTE]

## Целевая аудитория

Данные документы предназначены для следующих разработчиков:

- Разработчики, уже знакомые с основными функциями ErisPulse
- Разработчики, желающие глубже понять внутренние механизмы фреймворка
- Разработчики, которым необходимо оптимизировать производительность или реализовать сложные функции
