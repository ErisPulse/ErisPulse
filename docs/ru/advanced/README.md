# Продвинутые темы

В этом каталоге собраны продвинутые тематические материалы фреймворка ErisPulse — управление правами доступа, канареечные релизы, многоэтапное взаимодействие, бэкенды хранения
и другие глубокие возможности; каждая статья решает конкретный класс задач.

> [!NOTE]
> Все документы в этом каталоге — тематические статьи **для изучения по мере необходимости**. Сначала прочитайте пять основных статей уровня L1 на главной странице,
> а затем возвращайтесь сюда при возникновении соответствующих задач. В начале каждой статьи указано «когда следует читать эту статью».

## Четыре обязательные статьи L2

Четыре статьи, без которых не обойтись при написании production-модулей; рекомендуется прочитать их целиком перед созданием сложных модулей (подход согласован с главной страницей документации):

- [Область видимости (scope)](scope.md) - трёхмерное управление областью видимости: доступность модулей / допуск событий / ограничения исходящих действий (включая правила детальной гранулярности на уровне методов и merge при наследовании привязок)
- [Система владения (owner)](ownership.md) - принадлежность ресурсов и автоматическое освобождение: механизм owner-контекста, полный обзор принадлежащих ресурсов, последовательность очистки при выгрузке, границы hot reload и границы дизайна
- [Управление жизненным циклом](lifecycle.md) - система событий жизненного цикла: что именно делать при загрузке, выгрузке, перезагрузке и отключении модулей / адаптеров
- [Система интерактивных сессий](interaction.md) - wait_reply / таймеры сессий / многоканальное ожидание / взаимоисключающая аренда сессий / входящие сообщения / транзакции сообщений / трассировка цепочки вызовов

## Группировка по сценариям

Группировка согласована с разделом «Глубокое понимание принципов» на главной странице документации; первая статья каждой группы снабжена пометкой «каких подводных камней ждать без понимания».

**Запуск и инициализация** — без понимания цепочки запуска (Finder / Loader / Manager / Router) при сбое загрузки модуля остаётся лишь бессильно смотреть в логи

- [Процесс запуска и ручное управление](startup.md) - Разбор цепочки запуска (Finder/Loader/Manager/Router) и полный ручной запуск
- [Система ленивой загрузки](lazy-loading.md) - Принцип работы системы ленивой загрузки модулей, конфигурация и событийная ленивая активация (activate_on)

**Коммуникация и соединения** — без понимания белого списка сервисных контрактов (`meta.services`) межмодульный `module.call` будет отклонён с `ServiceNotProvidedError`, и причина останется неизвестной

- [Межмодульная коммуникация](module-communication.md) - RPC-протоколирование (module.call), сервисные контракты и каталог, направленные события, воспроизведение при холодном старте, идемпотентная дедупликация событий
- [Пул соединений и рассылка](connections.md) - Реестр соединений: рассылка, групповые подписки, межмодульная передача и переиспользование, просмотр пула соединений
- [Менеджер маршрутов](router.md) - Управление HTTP- и WebSocket-маршрутами (включая регистрацию с одним параметром и соглашение о кортежных ответах)

**Хранение данных** — без понимания семантики периода охлаждения после сбоя соединения при нестабильности базы данных легко ошибочно решить, что «фреймворк упал» (на самом деле это быстрый отказ с автоматическим переподключением после периода охлаждения)

- [Бэкенды хранения](storage-backends.md) - Выбор, конфигурация и переключение асинхронных нативных бэкендов хранения sqlite / mysql / postgres
- [Конструктор SQL-запросов](sql-builder.md) - Универсальный цепочный конструктор SQL-запросов и абстракция бэкендов хранения
- [Сетевой клиент](client.md) - Унифицированный клиент HTTP-запросов

**Сообщения и диалоги** — без понимания взаимоисключающей аренды сессий два модуля, ожидающие ответа одного и того же пользователя, будут отключать друг друга

- [Conversation: многоходовые диалоги](conversation.md) - Методы взаимодействия с контекстом многоходового диалога
- [Входящие сообщения сессии](transcript.md) - Автоматическая запись сообщений: регуляторы политики хранения, API переопределения во время выполнения, риски и аудит
- [Подробно о MessageBuilder](message-builder.md) - Двухрежимное использование конструктора сегментов сообщений OneBot12
- [Интернационализация (i18n)](i18n.md) - Поддержка нескольких языков, регистрация переводов и определение языка

**Теневое канареечное тестирование** — если перевести тень в полноценный режим раньше времени, не разобравшись в пяти барьерах изоляции, её исходящие сообщения утекут к реальным пользователям

- [Теневые модули и канареечный выпуск](shadow.md) - Параллельный пробный запуск новой версии модуля с независимым владельцем (owner): перехват и учёт исходящих сообщений, сравнение diff поведения, перевод через promote и откат при сбое

**Производительность и наблюдаемость** — если при возникновении проблем вы умеете только перезапускать систему и не смотрите на метрики — это полёт вслепую

- [Бенчмарки и тюнинг производительности](performance.md) - Реальные измеренные показатели (включая сравнение с NoneBot2), методика самостоятельного запуска бенчмарков и регрессионного сравнения, ключевые моменты тюнинга

**Исключения и справочник стандартов**

- [Система исключений и руководство по перехвату](errors.md) - Все типы исключений фреймворка, места их возникновения и рекомендации по перехвату
- [Система типов сессий](../standards/session-types.md) - Определение типов сессий, маппинг и регистрация пользовательских типов
