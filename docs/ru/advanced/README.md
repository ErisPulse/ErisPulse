# Расширенные темы

Данный раздел содержит расширенные возможности и углубленные темы фреймворка ErisPulse.

## Список документации

- [Процесс запуска и ручное управление](startup.md) - Разбор цепочки запуска (Finder/Loader/Manager/Router) и ручной полный запуск
- [Ленивая загрузка системы](lazy-loading.md) - Принцип работы системы ленивой загрузки модулей, конфигурация и событийная активация (activate_on)
- [Область видимости (scope)](scope.md) - Трехмерное управление областями видимости: доступность модуля / доступ к событиям / ограничения исходящих действий (включая мелкозернистые правила на уровне методов и наследование привязок merge)
- [Система владения (owner)](ownership.md) - Владение ресурсами и автоматическая очистка: контекст владения, карта ресурсов, последовательность очистки при выгрузке и границы проектирования
- [Международная локализация (i18n)](i18n.md) - Поддержка нескольких языков, регистрация переводов и определение языка
- [Управление жизненным циклом](lifecycle.md) - Использование системы событий жизненного цикла
- [Менеджер маршрутизации](router.md) - Управление маршрутизацией HTTP и WebSocket
- [HTTP-клиент](http-client.md) - Единый HTTP-клиент для запросов
- [Подробное руководство MessageBuilder](message-builder.md) - Двухрежимное использование MessageBuilder OneBot12 для построения сообщений
- [SQL-конструктор запросов](sql-builder.md) - Общий SQL-конструктор цепочечных запросов и абстракция хранилища
- [Система типов сессий](../standards/session-types.md) - Определение типов сессий, сопоставление и регистрация пользовательских типов
- [Conversation многоконтекстный диалог](conversation.md) - Методы взаимодействия многоконтекстного диалога

> [!NOTE]
> Документация по модулям сторонней экосистемы, таким как Dashboard и Takumi, была перемещена в каталог [Экосистема модулей](../ecosystem/README.md).

## Целевая аудитория

Данные документы предназначены для следующих разработчиков:

- Разработчики, уже знакомые с основными функциями ErisPulse
- Разработчики, желающие глубже понять внутренние механизмы фреймворка
- Разработчики, которым необходимо оптимизировать производительность или реализовать сложные функции
