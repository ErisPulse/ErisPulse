## Для кого эта документация

Эти документы предназначены для следующих разработчиков:

- уже освоивших базовые возможности фреймворка ErisPulse
- нуждающихся в глубоком понимании внутренних механизмов фреймворка
- разрабатывающих приложения, требующие оптимизации производительности или реализации сложных функций
