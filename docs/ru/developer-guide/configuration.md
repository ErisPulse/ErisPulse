# Конфигурация и метаданные пользовательского интерфейса

> Область применения: все объявления конфигурации, наследующие `BaseConfig` / `BotAccountConfig` (глобальные настройки адаптера, настройки аккаунта, настройки модуля).

Система конфигурации ErisPulse является **декларативной**: разработчики описывают параметры конфигурации с помощью полей dataclass и метаданных, а фреймворк `get_config_schema()` преобразует их в JSON Schema, который может быть использован любым потребителем (панель управления, сторонняя панель, CLI-модуль и т.д.) для отображения. В этой статье приведено **нормативное определение** этих метаданных — семантика виджетов, форма значений, условия отображения и обязательства по совместимости определяются исключительно здесь; конкретная реализация за потребителями, но семантика должна соответствовать этой статье.

## Структура объявления

```python
from dataclasses import dataclass, field
from ErisPulse.Core.Bases import BaseConfig, BotAccountConfig

@dataclass
class MyAdapterConfig(BaseConfig):
    """Глобальная конфигурация адаптера"""

@dataclass
class MyAccountConfig(BotAccountConfig):
    """Конфигурация аккаунта (адаптер с несколькими аккаунтами)"""
    token: str = field(
        default="",
        metadata={
            "description": "Токен доступа",
            "required": True,
            "secret": True,
            "ui": {
                "widget": "password",
                "group": "basic",
                "order": 1,
                "placeholder": "Вставьте токен платформы",
            },
        },
    )
```

## Основные метаданные (ключи верхнего уровня metadata)

| Ключ | Тип | Семантика |
|---|---|---|
| `description` | `str` или `{"i18n": ключ, "default": текст}` | Описание параметра (поддержка ссылок на i18n) |
| `required` | `bool` | Обязательный (валидация и подсказка в UI; если обязательное поле аккаунта пустое, при оплате можно уведомить, что конфигурация не завершена) |
| `secret` | `bool` | Сенсорное значение: в UI должно отображаться как пароль, маскировка в логах |

## UI-метаданные (подтаблица `metadata["ui"]`)

`ui` — стандартный ключ; `webui` — устаревшее альтернативное имя (эквивалентно, потребители должны поддерживать оба).

### Типы контейнеров (`list[T]` / `dict[str, T]`)

При аннотации полей **типизированными контейнерами** тип элементов автоматически попадает в схему:

- `list[int]` / `list[str]` и т.д. — массивы скаляров: схема содержит `item` (саму схему скалярного элемента),
  и при отсутствии объявления `widget` автоматически выводится как `list` (панель отображается как динамический список строк)
- `list[SomeDataclass]`: `item` — это `{"type": "object", "fields": {...}}`,
  панель отображается как **объектная строка с несколькими полями** (вложенные поля поддерживают все виды контроллеров и привязки)
- `dict[str, T]`: динамическая таблица ключей, `item` содержит тип значений; панель отображается как редактор пар ключ-значение
- Явное объявление `ui.item` имеет приоритет над автоматически сгенерированным (явное объявление перекрывает вывод)

При загрузке (`dict_to_dataclass`) элементы преобразуются согласно объявленным типам: скаляры преобразуются в типы (например, `["1", 2.0]` → `[1, 2]`), элементы dataclass инстанцируются (неконтейнерные скаляры обёртываются в первый элемент), а строка JSON сначала парсится (режим редактирования JSON на панели / перезапись через env).
При валидации (`validate_config`) рекурсивно проверяются типы элементов и вложенные ограничения полей dataclass,
ошибки сопровождаются путями к элементам (например, `rules[0]` / `quotas.q`).

В TOML-шаблоне элементы / значения контейнеров, являющихся dataclass, отображаются как `[[таблица массива]]` / `[таблица.ключ]` (при наличии элементов — раскрываются поэлементно, при отсутствии — выводится шаблон с комментариями; пустые контейнеры **не записываются** `ключ = []` — статический пустой массив и последующее добавление `[[ключ]]` исключают возможность дальнейшего добавления в виде массива таблиц).

```python
@dataclass
class RetryRule(BaseConfig):
    host: str = field(default="", metadata={"description": "Целевой хост"})
    port: int = field(default=0, metadata={"description": "Порт", "required": True})

@dataclass
class MyConfig(BaseConfig):
    rules: list[RetryRule] = field(default_factory=list)   # Панель: список строк объектов
    quotas: dict[str, RetryRule] = field(default_factory=dict)  # Панель: таблица ключ-значение
    nums: list[int] = field(default_factory=list)          # Панель: список строк со скалярными значениями
```

### Общие ключи

| Ключ | Семантика |
|---|---|
| `widget` | Тип контрола (см. список видов контрола); при отсутствии выводится по типу поля |
| `group` | Название группы; для групп с одинаковым именем отображаемое имя предоставляется через `_schema_meta["group_labels"]` (также поддерживается словарь i18n) |
| `order` | Вес сортировки внутри группы (меньший вес — выше, по умолчанию 100) |
| `options` | Список вариантов `[{label, value}]` (для `label` поддерживается словарь i18n; используется в `select`/`multiselect`) |
| `placeholder` | Текст-заполнитель для ввода (поддерживается словарь i18n) |
| `min` / `max` / `step` | Диапазон и шаг (для `number`/`slider`) |
| `rows` | Количество строк для многострочного текста (для `textarea`) |
| `presets` | Палитра предустановленных цветов (для `color`; `["#rrggbb", ...]`, по умолчанию — встроенная палитра потребителя) |

### Условное отображение/отключение (взаимодействие полей)

| Ключ | Семантика |
|---|---|
| `show_if` | При невыполнении условия поле **скрывается** (значение сохраняется, но не удаляется) |
| `disabled_if` | При выполнении условия поле **отключается** (отображается серым, значение сохраняется) |

Объект условия: `{"field": <имя поля в том же контексте или полный ключ конфигурации>, "op": <оператор>, "value": <сравниваемое значение>}`. Список операторов:

| op | Семантика |
|---|---|
| `eq` / `ne` | Равно / не равно (сравнение после преобразования в строку) |
| `in` / `nin` | `value` — массив, элемент / не элемент |
| `gt` / `gte` / `lt` / `lte` | Числовое сравнение |
| `truthy` | Истинное значение (не пустое, не `"false"`, не `"0"`) |

По умолчанию `op` — `eq`. При разрешении полей сначала используется **короткое имя в том же контексте**, затем полный ключ (например, `accounts.default.mode`).

### Формат значения (`value_type`, используется в `multiselect`)

| Значение | Формат хранения | Применение |
|---|---|---|
| `json` (по умолчанию) | JSON-строка массива (например, `"[0, 25]"`) | Тип поля — `str`, массив хранится как текст JSON |
| `array` | Нативный массив | Тип поля — `list` |
| `mask` | Целочисленный битовый маска (выбранные значения суммируются как `2^v`) | Тип поля — `int` для битовых флагов, `options[].value` — номер бита |

**Обязанности потребителя**: при отсутствии `value_type` необходимо выводить по типу поля (если `int` и цифровые варианты → `mask`; `list` → `array`; иначе `json`), чтобы при объявлении только `widget: multiselect` записывался корректный тип.

## Справочник виджетов

Потребитель должен реализовать следующую семантику; **неизвестные виджеты должны возвращаться к однорядному тексту**, без ошибок.

| Виджет | Тип значения | Семантика |
|---|---|---|
| `text` | str | Однорядный текст (по умолчанию возврат к тексту) |
| `textarea` | str | Многострочный текст (`rows`) |
| `password` | str | Пароль (`secret: True` автоматически определяется) |
| `number` | int/float | Ввод числа (`min`/`max`/`step`; автоматически определяется для числовых полей) |
| `switch` | bool | Переключатель (автоматически определяется для bool полей) |
| `select` | str | Единый выбор из выпадающего списка (`options`; автоматически определяется для строковых полей с options) |
| `multiselect` | См. тип значения | Множественный выбор (группа флажков; `options` + `value_type`) |
| `slider` | int/float | Ползунок (`min`/`max`/`step`) |
| `color` | str | Цвет (`#rrggbb`) |
| `date` / `time` / `datetime` | str | Дата / Время / Дата и время (строка в формате ISO) |
| `kv` | dict | Редактор ключ-значение (`dict[str, str]`) |
| `list` | list | Редактор списка (`item` объявляет поля в строке: `{"widget": ...}` или `{"fields": {...}}` поддерживает вложенные поля; автоматически определяется для типизированных массивов) |

## Контракт совместимости (должен соблюдаться потребителями)

1. **Игнорировать неизвестные ключи**: при появлении в метаданных ключей, не описанных в спецификации (включая будущие добавления), игнорировать их без ошибки.
2. **Вернуться к text для неизвестного widget**: обеспечить, чтобы новые объявления оставались редактируемыми на старых потребителях.
3. **Условие не выполнено ≠ удаление значения**: значения полей, скрытых через `show_if`, сохраняются без изменений.
4. **Типизация по умолчанию**: при отсутствии расширенных ключей, таких как `value_type`, корректно определять форму хранения на основе типа поля.

## Полный пример

```python
@dataclass
class OneBotAccountDemo(BotAccountConfig):
    mode: str = field(
        default="server",
        metadata={
            "description": "Режим подключения",
            "ui": {
                "widget": "select",
                "group": "connection",
                "order": 1,
                "options": [
                    {"label": "Server (пассивный)", "value": "server"},
                    {"label": "Client (активный)", "value": "client"},
                ],
            },
        },
    )
    url: str = field(
        default="ws://127.0.0.1:3001",
        metadata={
            "description": "Адрес WebSocket",
            "ui": {
                "widget": "text",
                "group": "connection",
                "order": 2,
                "show_if": {"field": "mode", "op": "eq", "value": "client"},
            },
        },
    )
    intents: int = field(
        default=33281,
        metadata={
            "description": "Маска битов (поле типа int, автоматически хранится по маске)",
            "ui": {
                "widget": "multiselect",
                "group": "advanced",
                "order": 3,
                "options": [
                    {"label": "Основа каналов", "value": 0},
                    {"label": "Сообщения каналов", "value": 9},
                    {"label": "Содержание сообщений (привилегии)", "value": 15},
                ],
            },
        },
    )
```

## Схема вывода

`ErisPulse.Core.Bases.config_schema.get_config_schema(cls)` выводит JSON-схему (поля/группы/account_based/метаданные), и **прозрачно передает** все ключи подтаблицы `ui`, определённые в настоящем документе, для прямого использования потребителями.
