# Руководство для разработчиков

> [!TIP]
> **Когда читать этот документ**: когда вы готовитесь разрабатывать расширения для ErisPulse — добавлять боту новые функции (модули) или подключать новые платформы (адаптеры). Если вы просто хотите пользоваться ботом, пропустите этот документ и переходите сразу к [Быстрому старту](../quick-start.md).

Здесь вы найдёте свой путь разработки: **разработка модулей** позволяет расширять функциональность бота с помощью команд и обработчиков сообщений; **разработка адаптеров** позволяет подключить бота к новым платформам обмена сообщениями. Оба пути охватывают полный процесс — от создания проекта до тестирования и публикации.

## Подготовка к разработке

Прежде чем приступить к разработке, убедитесь, что вы:

1. Прочитали [Основные понятия](../getting-started/basic-concepts.md)
2. Ознакомились с [Обработкой событий](../getting-started/event-handling.md)
3. Установили среду разработки (Python >= 3.10)
4. Установили ErisPulse SDK

## Выбор типа разработки

Выберите подходящий тип разработки в зависимости от ваших потребностей:

| Тип разработки | Сценарии использования | Руководство по началу работы |
|----------------|------------------------|------------------------------|
| **Разработка модуля** | Расширение функциональности бота, реализация бизнес-логики, предоставление команд и обработки сообщений | [Введение в разработку модулей](modules/getting-started.md) |
| **Разработка адаптера** | Подключение к новой платформе сообщений, реализация межплатформенной связи, предоставление функций, специфичных для платформы | [Введение в разработку адаптеров](adapters/getting-started.md) |

> Если вы хотите расширить функциональность бота (например, добавить команды или обрабатывать сообщения), выберите **разработку модуля**. Если вам нужно подключить бота к новой платформе, выберите **разработку адаптера**.

### Режим разработки

Для разработки используйте режим горячей перезагрузки, при котором изменения в коде автоматически перезагружаются:

```bash
epsdk run main.py --reload
```

### Техники отладки

В файле `config/config.toml` включите уровни логирования DEBUG или TRACE:

```toml
[ErisPulse.logger]
# DEBUG: Вывод информации о загрузке модулей, регистрации маршрутов и других отладочных данных
# TRACE: Самый низкий уровень, вывод подробных внутренних процессов фреймворка, таких как распределение событий, запись в хранилище и ленивая загрузка
level = "DEBUG"
```
