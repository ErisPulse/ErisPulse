## Подготовка к разработке

Перед началом разработки убедитесь, что вы:

1. Прочитали [Основные понятия](../getting-started/basic-concepts.md)
2. Изучили [Обработку событий](../getting-started/event-handling.md)
3. Установили среду разработки (Python >= 3.10)
4. Установили SDK ErisPulse

## Выбор типа разработки

Выберите подходящий тип разработки в зависимости от ваших потребностей:

### Разработка модулей

**Сценарии применения:**
- Расширение функционала бота
- Реализация конкретной бизнес-логики
- Обеспечение обработки команд и сообщений

**Примеры:**
- Бот для проверки погоды
- Музыкальный плеер
- Инструмент для сбора данных

**Руководство для начинающих:** [Введение в разработку модулей](modules/getting-started.md)

### Разработка адаптеров

**Сценарии применения:**
- Подключение к новым платформам сообщений
- Реализация межплатформенной коммуникации
- Предоставление функций, специфичных для платформы

**Примеры:**
- Адаптер для Discord
- Адаптер для Slack
- Кастомный адаптер платформы

**Руководство для начинающих:** [Введение в разработку адаптеров](adapters/getting-started.md)

## Инструменты разработки

### Шаблоны проектов

ErisPulse предоставляет примеры проектов для справки:

- `examples/example-module/` - Пример модуля
- `examples/example-adapter/` - Пример адаптера

### Режим разработки

Используйте режим горячей перезагрузки для разработки:

```bash
epsdk run main.py --reload
```

### Советы по отладке

Включите логирование уровня DEBUG:

```toml
[ErisPulse.logger]
level = "DEBUG"
```

Используйте свой логгер модуля:

```python
from ErisPulse import sdk

logger = sdk.logger.get_child("MyModule")
logger.debug("Отладочная информация") # Отладочная информация
```

## Публикация вашего модуля

Полный процесс публикации см. в разделе [Руководство по публикации и магазину модулей](publishing.md), включая:

- Шаги по публикации в PyPI
- Процесс подачи на рассмотрение в магазин модулей ErisPulse
- Публикация адаптеров

### Справочные материалы

```bash
# Построение и публикация в PyPI
python -m build
python -m twine upload dist/*
```

Затем перейдите по ссылке [ErisPulse-ModuleRepo](https://github.com/ErisPulse/ErisPulse-ModuleRepo/issues/new?template=module_submission.md), чтобы отправить проект в магазин модулей.
