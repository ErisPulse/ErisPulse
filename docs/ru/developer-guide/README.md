## Подготовка к разработке

Перед началом разработки убедитесь, что вы:

1. Прочитали [Основные концепции](../getting-started/basic-concepts.md)
2. Ознакомились с [Обработкой событий](../getting-started/event-handling.md)
3. Установили среду разработки (Python >= 3.10)
4. Установили SDK ErisPulse

## Выбор типа разработки

Выберите подходящий тип разработки в зависимости от ваших потребностей:

| Тип разработки | Сценарий применения | Руководство по началу |
|----------------|---------------------|-----------------------|
| **Разработка модулей** | Расширение функциональности робота, реализация бизнес-логики, предоставление команд и обработки сообщений | [Введение в разработку модулей](modules/getting-started.md) |
| **Разработка адаптеров** | Подключение новых платформ сообщений, реализация межплатформенной связи, предоставление платформенно-специфических функций | [Введение в разработку адаптеров](adapters/getting-started.md) |

> Если вы хотите расширить функциональность робота (например, добавить команды или обрабатывать сообщения), выберите **разработку модулей**. Если вам нужно подключить робота к новой платформе, выберите **разработку адаптеров**.

### Режим разработки

Используйте режим горячей перезагрузки для разработки, чтобы код автоматически перезагружался после изменений:

```bash
epsdk run main.py --reload
```

### Техники отладки

Включите логирование уровня DEBUG или TRACE в файле `config/config.toml`:

```toml
[ErisPulse.logger]
# DEBUG: Вывод информации о загрузке модулей, регистрации маршрутов и т.д.
# TRACE: Самый низкий уровень, вывод подробных внутренних процессов фреймворка, таких как распределение событий, запись в хранилище, ленивая загрузка и т.д.
level = "DEBUG"
```
