# 代码与注释规范

## 注释与 docstring（强约束）

- 注释只写客观事实（代码做什么、契约与外部约束）；**禁止解释性注释**——不写设计缘由、背景故事、决策过程、改动动机，不写"我们/本脚本"式叙述，不引用历史事故
- 模块顶部 docstring：模块名 + 功能描述 + `{!--< tips >!--}…{!--< /tips >!--}` 使用要点 + `:example:` 可运行示例
- 方法 docstring 格式：

```python
def func(param1: type1, param2: type2 = None) -> ret_type:
    """
    [功能描述]

    :param param1: [类型] [描述]
    :param param2: [类型] [描述] (默认: None)
    :return: [返回类型] [描述]
    :raises ErrorType: [触发条件]

    :example:
    >>> result = func(1)
    """
```

- 特殊标签：`{!--< internal-use >!--}` 不生成 API 文档；`{!--< ignore >!--}` 跳过；tips 块用于重要用法提示
- 模块顶部**不允许自由函数**：仅单类使用的私有方法/闭包收进类内；跨类复用才提升为模块级函数（公共 API 需进 `__all__`）

## 工程健壮性纪律

**异常留痕分级**（`except` 不是垃圾桶）：

| 类别 | 判定 | 处理 |
|------|------|------|
| 探测型 | 有安全默认值且失败无害 | `pass` 可接受 |
| 降级型 | 走替代路径但值得知道 | `logger.debug` |
| 资源释放型 | 连接/句柄/线程/任务关闭 | 至少 `debug`，重复出现升 `warning` |
| 数据写入型 | 配置落盘/持久化 | `warning` 起步——静默丢数据不可排查 |

- 禁止双层降级（不要把日志调用再包 `try/except: pass`）
- 失败事件最低 `warning`；循环内失败节流（首次 warning + 计数/冷却）；`trace` 只给热路径正常流水；`error` 留给已影响请求结果的失败

**行为参数集中**：超时/重试/冷却/阈值一律定义在 `Core/constants.py`（核心仓库），命名 `*_TIMEOUT_SECS` / `*_RETRY_*`，注释写明使用位置。实现文件禁止裸数字超时。第三方模块/适配器在自身模块内集中定义即可。

**公共 API 契约**：无下划线前缀的类与方法必须有完整 docstring + 全参数/返回值类型标注；新增/修改公共 API 时同步 `__all__`、聚合导出文件、示例项目。

**单例回引禁忌**：框架组件不得持有根 SDK 单例回引字段——构造注入或惰性解析二选一；需要他人状态走事件订阅或门面。

**清理纪律**：卸载/清理路径幂等；不可逆操作前拍快照；清理顺序 任务取消 → 连接关闭 → 外部钩子 → 注册表回收，单步失败不阻断后续。

## 配置系统要点

- 配置写入走 tomlclass 无损编辑路径（注释/顺序/逐字节保真），禁止 `toml.dump` 纯 dict 序列化
- 行为参数（重试/超时/冷却/阈值）必须定义在 `Core/constants.py` 并注明使用位置
- 存储约定：连接失败不阻塞框架（冷却期快速失败）；操作执行失败抛 `StorageOperationError`
- 新异常挂 `Core/Bases/errors.py` 的 `ErisPulseError` 层级、从 `ErisPulse.Core` 聚合导出、同步 `errors.md`
